# 화면별 설명 (경로 · 기능 ID · 코드 위치)

- 기능 ID는 시트 「Final Project 3조 기능 명세서」의 **`기능 명세서 v3`** 탭 번호입니다.
- 코드 위치는 `src/` 기준이고, 캡처는 `screenshots/` 폴더에 같은 번호로 있습니다.
- 경로는 주소의 해시입니다. 예: `avenue-demo-v2.html#report`.

## 로그인 전 (공개 화면)

### 01 메인(홍보) 페이지 · `#main` · `screenshots/01-main.png`
- **기능 ID:** N-10 (N-10-1 전후 점수 카드, N-10-2 12개월 추이 그래프)
- **코드:** `20_auth.js` `vMain`, `promoChart`
- 헤더 오른쪽에 [로그인]·[회원가입]이 있습니다. 로그인한 상태로 오면 [내 리포트로](관리자는 [관리자 화면으로])와 [로그아웃]이 보입니다.
- 예시 값은 640점(Caution) → 778점(Standard)이며, 고정 예시 데이터입니다.

### 02 로그인 · `#login` · `02-login.png`
- **기능 ID:**
  - N-01-1 로그인, N-01-2 역할별 첫 화면, N-01-3 잠긴 계정, N-01-5 시연 계정, N-01-6 소셜 로그인
  - 관리자 2단계 인증은 `30-admin-2fa.png`
- **코드:** `20_auth.js` `vLogin`, `F.login`, `F.tfa`, `socialModal`, `A.social*`, `startSession`
- 5번 틀리면 계정이 잠깁니다. 잠긴 계정은 [아이디·비밀번호 찾기]에서 비밀번호를 다시 설정하면 풀립니다.
- ⚠️ 데모는 있는 아이디에 비밀번호만 틀리면 "비밀번호가 맞지 않습니다 (n/5회)"라고 알려 줍니다. v3 N-01-1은 "무엇이 틀렸는지 알려 주지 않는다"이므로, 구현할 때는 명세를 따릅니다. 남은 횟수 안내를 어떻게 할지는 팀 확인이 필요합니다.
- 소셜 로그인은 Google·카카오·네이버입니다. 처음 쓰는 소셜 계정이면 [기존 계정에 연결]이나 [새로 가입]을 고릅니다. 관리자는 쓸 수 없습니다.
- **첫 화면:**
  - 관리자 → 2단계 인증(코드는 시연이라 화면에 표시) → `#a-model`
  - 사용자 → 직군 없음 `#job` / 진단 기록 없음 `#input` / 그 밖 `#report`

### 03 회원가입 · `#signup` · `03-signup.png`

- 인증코드는 시연이라 화면에 표시됩니다. 직군은 받지 않고 로그인 후 고릅니다.

### 04 아이디·비밀번호 찾기 · `#find` · `04-find.png`

### 11 자산·부채 건전성 · `#health` · `11-health.png`
- **기능 ID:** N-16 (N-16-1 지표 계산, N-16-2 위험 단계, N-16-3 값 바꿔 보기·되돌리기, N-16-4 보유 대출 표), N-15 같은 직군 평균과 비교

- ⚠️ 화면 큰 제목이 옛 이름 "직군별 재무 진단"으로 남아 있습니다. 메뉴 이름은 '자산·부채 건전성'입니다.

### 12 시나리오 테스트 · `#stress` · `12-stress.png`
- **기능 ID:** N-17 (N-17-2 시나리오 입력, N-17-4 상환 여력 재계산, N-17-5 현재·시나리오 비교)
- **코드:** `30_user.js` `vStress`, `rangeNum`, `A.preset`
- **상황 버튼:**
  - 나빠지는 경우: 금리 +1·+2%p, 소득 −20%, 악화 복합
  - 좋아지는 경우: 금리 −1%p, 소득 +10%, 지출 −10%, 호전 복합
- **슬라이더:** 금리 −2~+3%p, 소득 −50~+30%, 지출 −30~+30%
- **숫자 직접 입력:** 금리 −5~+10%p, 소득 −100~+100%, 지출 −50~+100%
- 금리 변화는 변동금리 대출에만 적용합니다. 결과는 월 잉여, 상환 부담률, 월 이자 변화, 버틸 수 있는 개월 수입니다.

### 14 상권 분석 · `#area` · `14-area.png`, `14b-area-dark.png`
- **기능 ID:** N-24 (N-24-3 차트, N-24-4 지도 히트맵, N-24-5 행정동 상세 창)
- **코드:** `30_user.js` `vArea` (틀), `40_admin.js` `mountHeat` (iframe), `src/heatmap/seoul-heatmap.html` (히트맵 본체)
- **조건:** 지표 5개(분기 폐업률·매출 전년비·개업률·점포 수 증감·유동인구 증감), 업종 8개, 구 선택, 행정동 검색
- 색은 기본 초록, 나쁨 선홍, 좋음 연청입니다. 지도 아래 한 줄에 요약 · 구별 평균 · 행정동 분포 · 주의할 동/좋은 동이 있습니다.

- 자영업자는 내 사업장 동(서교동)에서 시작하고, 다른 직군은 서울 전체에서 시작합니다.
- 지도는 도식이고 데이터는 예시입니다. 실제로는 지도 API와 행정동 GeoJSON을 씁니다.
