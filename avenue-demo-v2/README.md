## 이 폴더를 읽는 AI에게 (Claude Code · VSCode 확장)

1. **이 데모는 화면·흐름의 기준이지, 옮겨 쓸 코드가 아닙니다.**
   - 실제 서비스는 프론트엔드·백엔드 저장소 구조와 `AGENTS.md` 규칙을 따릅니다.
   - 데모는 화면 전체를 `innerHTML`로 다시 그리는 단순 구조입니다. 이 구조를 그대로 옮기지 않습니다.
2. **숫자는 전부 예시입니다.**
   - 점수 엔진(`10_core.js`의 `factors`·`scoreOf`)은 화면을 움직이려고 만든 가짜 모델입니다. 실제 모델·가중치가 아닙니다.
   - 대출 상품(`LOANS`), 통계(`STAT`·`CMP`), 상권 데이터, 게시글, 회원도 모두 시연용입니다.
3. **기능 이름·번호는 시트의 `기능 명세서 v3` 기준입니다.**
   - 데모 코드 주석에 남은 옛 번호(v1·v2)보다 `SCREENS.md`의 대응표를 우선합니다.
   - 명세와 데모가 다르면 임의로 고르지 말고 사용자에게 묻습니다.
4. **확정된 UI 결정**(아래 표)은 다시 제안하지 않습니다. 바꾸려면 사용자 확인이 필요합니다.
5. **"남아 있는 옛 코드"**(아래 목록)는 확정 UI에 없는 기능입니다. 구현 근거로 쓰지 않습니다.
6. 화면 모양은 `screenshots/`의 PNG로 확인합니다. 파일 이름은 `SCREENS.md`의 번호와 같습니다.

## 코드 구조 요약 (읽는 순서)

1. **상태**
   - `S`: 저장되는 데이터. 회원, 글, 로그, 감사 로그, 알림, 테마.
   - `UI`: 저장되지 않는 화면 상태. 입력 중인 값, 열린 창.
   - 처음 값은 `seed()`와 `freshUI()`가 만듭니다(`10_core.js`).
2. **그리기**
   - `render()`가 `ROUTES[해시]()`로 화면 HTML 문자열을 만들어 `#app`에 넣습니다.
   - 화면 함수 이름은 `v` + 화면명입니다(`vReport`, `vSim`, `vAModel` …).
   - 사용자 화면은 `userShell()`, 관리자 화면은 `adminShell()`로 헤더·메뉴를 감쌉니다.
3. **동작**
   - 버튼은 `data-a="이름"` → `A.이름(dataset, el)`을 부릅니다.
   - 폼은 `data-f="이름"` → `F.이름(form)`을 부릅니다.
   - 입력칸은 `data-bind="UI 경로"`로 값이 `UI`에 들어갑니다. `data-live`가 붙은 칸은 입력할 때마다 다시 그립니다.
4. **테마**
   - CSS 변수 두 벌을 씁니다. `:root`는 블랙, `[data-theme="light"]`는 화이트(기본)입니다.
   - SVG 차트처럼 색을 직접 적은 곳은 `LIGHT_HEX` 표로 바꿔 끼웁니다.
5. **카드 접기**
   - `decorateCards()`가 사용자 화면의 카드마다 [접기] 버튼을 붙입니다.
   - 탭의 중심 그래프(`CARD_FIXED`)는 접을 수 없습니다.
6. **상권 히트맵**
   - `mountHeat()`가 iframe을 엽니다.
   - 자영업자는 내 사업장 동(서교동), 그 밖의 직군은 서울 전체에서 시작합니다.
   - 화이트 테마 CSS를 iframe 안에 넣고, 높이는 `postMessage`로 맞춥니다.

### 남아 있는 옛 코드 (확정 UI에 없음, 구현 근거로 쓰지 않음)

- `vGuest()`, `guestData()`, `UI.guest`: 비회원 예상 점수(N-36 삭제). 라우터에 연결되어 있지 않습니다.
- `finSub()`: 재무 진단 하위 탭. 첫 줄에서 `return ''` 합니다.
- `themeBtn()`: 헤더 테마 버튼. 빈 문자열입니다.
- `A.accRoleAsk` · `A.accRole` · `A.accRoleCancel`: 회원 → 관리자 권한 변경(삭제됨).
- `A.setTheme`, `A.toggleCard`, `A.showAllCards`, `A.cardShow`, `A.cardShowAll`: 마이 페이지 화면 설정·카드 숨기기(삭제됨).
- `A.noArea`: 화면에서 부르지 않습니다.
- 참고: `A.toggleEasy`(리포트의 '쉬운 말로 보기' 스위치)와 `A.simGo`(`A.simFill` 안에서 호출)는 `sw()`·함수 호출로 쓰이고 있으니 지우지 않습니다.
- CSS 변수 `--c-bonus`, `--c-bonus2`: 가산점 색(가산점 기능 삭제됨).
