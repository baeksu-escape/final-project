# 통계 근거와 가정

통계는 합성 분포의 기준점이며 실제 개인의 거래나 신용평가 효과를 입증하지 않는다. 출처가 있는 값과 프로젝트 가정을 구분해 적는다. 비금융 효과와 미납 규칙의 근거는 `NONFINANCIAL_LABEL.md`, 서비스 더미의 기준점은 `SERVICE_DUMMY_DATA.md`에 있다.

## 통계 원자료

원본 3개를 `reference/statistics/`에 두고, 각 파일의 SHA256과 사용한 숫자를 `reference/statistical_priors.json`에 기록했다. `python -m verify.verify_statistics`로 원본 셀과 JSON을 다시 대조한다. 수집 파일명의 날짜는 통계 기준시점과 다르다.

1. **연령대별 소득** (`연령대별_소득_20261023171123.csv`): 2024년 20~69세 연령대별 평균·중위 소득(만원/월). 급여소득자에만 적용하며, 각 평균·중위수를 만족하는 로그정규 분포를 기준으로 쓴다. 연령·신용이력·부채의 결합과 유한 표본 때문에 생성 집단의 평균·중위수는 원표와 정확히 같지 않다.
2. **소득구간별 가계수지** (`소득구간별_가구당_월평균_가계수지__도시_1인이상__….csv`): 2026년 2분기 전체 가구의 소득·소비지출·가구원수. 기준축은 가구소득/가구원수, 지출비율은 소비지출/가구소득이며 개인 월소득에 선형보간한다(양끝 고정). **가구 집계치를 개인에 옮기는 가정**이다. 1인 가구 통계가 아니고 규모의 경제·가구 내 소득 배분은 반영하지 못한다. 생활지출은 소비지출 대용치이며 세금·사회보험·이전지출은 차감하지 않는다.
3. **가계금융복지조사 부록** (`2025년+가계금융복지조사+부록+통계표.xlsx`): 1인 가구의 평균 자산(2025년)·저축액·가구소득(2024년). 평균 자산/평균 연소득 비율을 쓰며, `자산 = 연소득 × 비율 × 로그정규 잡음(sigma 0.6)`이다. 개인 자산/소득 비율의 평균으로 해석하지 않는다.

**유동자산** = 생성 자산 × (1인 가구 평균 저축액/평균 자산) × 접근가능비율 0.5. 접근가능비율은 근거가 부족한 가정이다. 지출 예산제약에 쓰는 `expense_drawdown_fraction` 0.5와는 다른 값이다.

## 비금융 원천과 비금융 효과 라벨

통신·공과금 미납 규칙과 비금융 효과 라벨의 근거는 `NONFINANCIAL_LABEL.md`, 간편결제·국민연금·건강보험 원천(v3.5.0)의 통계 기준점·제도 값·가정은 `NONFINANCIAL_SOURCES.md`와 `reference/nonfinancial_sources.json`에 따로 둔다.

## 소득과 부채의 결합

부채 순위와 소득을 가우스 코퓰라로 연결한다(잠재 혼합계수 rho 0.5, 가정). rho는 최종 Spearman 상관을 직접 지정하는 값이 아니다. 부채가 같은 고객(특히 무부채)은 동률 구간 안에서 균등한 위치를 무작위로 골라 정규 분위수로 바꾸고, 부채가 모두 같은 집단은 잡음을 줄이지 않는다.

## 의도적으로 남긴 가정과 해석 범위

| 항목 | 내용 | 해석 |
|---|---|---|
| 무부채 고객의 소득 위치 | 부채와 소득의 양의 상관 때문에 무부채 고객은 낮은 소득 쪽에 배정되는 경향이 있다. 무부채 비율이 높은 no_credit·sparse_history 집단의 소득 분포가 낮게 이동할 수 있다 | 합성 설계 가정이다. 실제 집단 특성처럼 설명하지 않는다 |
| 카드 이용액과 소득·생활비 | 카드 이용액에는 소득·생활비와의 직접 정합성 제약이 없다. 총사용액에는 현금서비스가 포함된다 | 이용액이 생활비나 소득을 넘는다는 것만으로 오류가 아니다 |
| 207열 카드 필드 | 씬파일 집단의 주사용 카드·30만원 조건 카드 필드와 `CS0000050`은 기존 집단과 같은 규칙(고객 단위 합성 대용치)으로 계산한다. 같은 열 이름이 두 집단에서 같은 의미를 갖게 하기 위해서다 | 계좌별 사실값이 아니다. 카드 1장 고객의 조건 필드가 전체 사용개월수보다 작을 수 있다. 계좌별 분석은 `card_account_monthly.csv`를 쓴다 |
| 미납과 금융 위험의 연동 | 최근 금융 연체가 있으면 통신·공과금 미납이 3배 잘 생기고, 미납은 다음 달 30% 확률로 이어진다 | 연구가 보여 준 방향에 맞춘 가정이다. 미납 비율 자체를 실제 통계처럼 설명하지 않는다 |
| 비금융 효과 라벨 | 별도 라벨에 미납 승산비 2.5와 약한 현금흐름 효과를 넣었다 | 이 라벨에서 얻은 성능 향상은 가정한 효과를 찾아낸 것이다 |

## 그 밖의 가정과 한계

- 자영업자·프리랜서의 소득 배수·분산, 월별 변동·계절성, 무소득월 확률(프리랜서 8%)은 가정이다. 사업소득 신고표는 개인 단위 대응이 확인되지 않아 쓰지 않았다.
- 통신·공과금 미납의 기본 발생률, 고정지출 65%, 최소생활비 연 1,200만 원, 연령 비중, 신용이력 시작 나이 19세는 가정이다.
- 기존 집단은 원본의 긴 신용이력 때문에 20대가 적다. 연령별 소득 반영이 연령 구성 문제를 해결하지는 않는다.
- 소득 원표 2024년, 자산 2025년, 지출 2026년 2분기, 가상 이력 2025-09~2026-08을 물가·추세 보정 없이 섞은 정적 시나리오다. 시점 기준 백테스트에 쓸 수 없다.
- 시나리오(`scenarios.csv`)는 입력 조건의 기계적 계산이다. 신용점수 상승이나 인과효과의 근거가 아니다.

## 자료가 있으면 개선할 부분

개인별 월간 소득·지출 패널, 직군별 무소득월 빈도, 1인 가구 소득구간별 생활지출, 즉시 인출 가능 예금 통계, 통신·공과금 미납 횟수·기간 분포, 직군·연령·소득·자산의 결합분포. 자료를 확보하기 전에는 지금의 가정을 사실처럼 표기하지 않는다.
