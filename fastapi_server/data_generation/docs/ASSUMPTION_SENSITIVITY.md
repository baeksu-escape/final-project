# 가정 민감도 실험

주요 가정을 한 번에 하나씩 바꿨을 때 현금흐름 지표와 씬파일 라벨이 어떻게 변하는지 보는 실험이다(`run_assumption_sensitivity.py`). 실제 모집단 추정이나 효과 검증이 아니며, 결과로 기본값을 최적화하지 않는다.

## 설계

기존 12,000명과 씬파일 2,400명을 각각 원래 시드로 다시 만든다. 기준 설정이 먼저 생성한 기준 데이터(`data/`, `thinfile/`)와 같은지 대조한 뒤 한 요인만 바꾼다. 같은 난수 흐름을 써서 가정 변경 외의 차이를 줄인다. 낮음·높음은 검증된 범위가 아니라 기준의 0.5배·1.5배 시연 범위다. 단일 시드이며 요인 간 상호작용은 보지 않는다.

| 요인 | 낮음 | 기준 | 높음 |
|---|---|---|---|
| 프리랜서 월별 무소득 확률 | 4% | 8% | 12% |
| 월별 소득 로그정규 sigma(급여/자영업/프리랜서) | .03/.15/.225 | .06/.30/.45 | .09/.45/.675 |
| 통신·공과금 미납 발생 모수 | ×0.5 | 기준 | ×1.5 |
| no_credit 미래 신용 사용 확률 | 17.5% | 35% | 52.5% |
| sparse_history 미래 신용 사용 확률 | 10% | 20% | 30% |

- 소득 sigma는 직군별 값을 같은 배율로 함께 바꾼다.
- 미납 요인은 공과금 발생확률과 통신 기본·공과금 연동 가산을 묶어 바꾼다. 금융 위험 배수(3.0)와 지속 확률(0.30)은 바꾸지 않는다.

## 결과 해석

- 연소득 총액을 먼저 만든 뒤 12개월로 나누므로, 무소득월이나 sigma를 바꿔도 연소득·연간 지출·연말 잔액·연간 적자 여부는 그대로다. 바뀌는 것은 월별 분포, 소득 변동계수, 적자 월수, 중간 자금 소진이다. 무소득월이 늘어도 다른 달 소득이 늘어 연소득이 보전되는 구조이며 실제 소득 감소를 뜻하지 않는다.
- 미납 요인은 미납 비율만 바꾸고 현금흐름과 기존 라벨은 바꾸지 않는다. 미납이 잔액에서 빠지거나 다음 달로 이월되는 장부 모델은 아니다.
- 미래 신용 사용 확률을 바꾸면 노출 고객 집합 자체가 달라진다. 전체 양성률과 노출 고객 기준 양성률을 함께 보고, 집단별 실제 위험 차이로 해석하지 않는다. 나머지 두 집단은 노출 설정이 그대로라 결과도 같다.

## 파일과 실행

`python -m experiments.run_assumption_sensitivity` 다음 `python -m verify.verify_assumption_sensitivity`. 결과는 `assumption_sensitivity/`에 생긴다.

| 파일 | 내용 |
|---|---|
| `config.json` | 기준 모수, 조건 설정, 시드 정책, 엔진 해시 |
| `customer_cashflow_sensitivity.csv` | 고객별 × 7개 조건 현금흐름 결과 |
| `cashflow_summary.csv` | 집단·직군별 요약 |
| `exposure_labels.csv` | 씬파일 고객 × 3개 조건의 실험 노출·라벨(원본 라벨 아님, 모델 입력 금지) |
| `exposure_summary.csv` | 전체·노출 고객 분모와 양성률 |
| `validation.json`, `independent_validation.json` | 기준 대조, 현금 항등식, 저장 결과 재집계 검사 |

`rho_sensitivity.py`(소득·부채 상관 rho)와 `expense_sensitivity.py`(유동자산 인출 비율)는 같은 목적의 보조 보고 스크립트이며 결과를 `data/`에 쓴다.
