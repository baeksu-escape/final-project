## 무엇을, 왜 바꿨나
- 팀원 MD 통합본이 AI가 매번 읽기에 너무 길고, 사람용 설명·토큰 절약 팁·아직 정하지 않은 설계 초안이 섞여 있었다.
- AI가 읽는 문서는 확정된 규칙과 사실만 남기고, 이유·사용법·프롬프트 요령은 사람용 PDF(`docs/guide/`)로 옮겼다.
- 팀원이 정할 설계(DB 테이블·컬럼, API 형식, 폴더 구조, 환경 세팅, 학습 데이터)는 삭제했다.
- 백엔드 보호 규칙 대신, DB·API·대량 백엔드 변경 시 로그를 반드시 남기는 규칙을 두었다.
