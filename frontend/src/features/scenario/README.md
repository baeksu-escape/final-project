# 시나리오 테스트 (N-17)

`getScenarioData(userId, workerTypeCode)`는 기존 진단 합성 데이터로 월 기준값을 만든다. 실제 API는 미연결이며 mock 모드에서만 조회한다. 금액은 원 단위이며 누락값은 null로 보존한다.

`calculateScenario(baseline, conditions)`는 금리 변화 −5~+10%p, 소득 −100~+100%, 지출 −50~+100%를 검증한다. 변동금리 대출 잔액에만 금리 변화를 적용하고 총자산의 25%를 부족액으로 나누어 버틸 개월을 계산한다. 상환 부담률은 공용 DSR 함수를 사용하며 점수는 계산하지 않는다. 산출 불가능한 값과 0 소득의 DSR은 null이다. 실제 API 계약과 서버 계산은 정해지지 않았다.
