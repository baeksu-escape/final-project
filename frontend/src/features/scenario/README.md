# 시나리오 테스트 (N-17)

`getScenarioBase()`는 로그인 회원의 저장 기준값을 서버에서 조회한다. 금액은 원 단위이며 미입력 자산과 정책금리는 null로 보존한다.

`recalculateMemberScenario(conditions)`는 서버에서 금리 변화 −5~+10%p, 소득 −100~+100%, 지출 −50~+100%를 검증하고 상환 여력을 계산한다. 첫 조건은 즉시 요청하며 이후 입력은 300ms 동안 모아 요청한다. 결과를 기다리는 동안 직전 결과를 유지하고 늦은 응답은 무시한다. mock 모드도 같은 API 경로를 사용한다.
