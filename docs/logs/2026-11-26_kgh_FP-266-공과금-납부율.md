# DIAG-03-1 공과금 기한 내 납부율 추가

- **날짜:** 2026-11-26
- **작성자:** kgh
- **브랜치:** KGH_Work에서 작업, PR 브랜치 feature-A/FP-266-asset-debt-feedback
- **관련 N-ID:** N-20-1, N-20-5
- **관련 결정:** 경환 승인, 광희 기준으로 조회 기간과 분모를 적용했다.

## 무엇을, 왜 바꿨나

- 회원의 가장 늦은 `IMPORTED` 청구월과 직전 11개월의 기관 연동 기록을 청구월 오름차순으로 반환한다. 달력 12개월 중 빈 달이 있으면 12건 미만을 반환한다.
- 기록이 있는 달을 분모로 기한 내 납부율을 계산한다. `ON_TIME`은 정시, `LATE`·`UNPAID`는 미납으로 센다. DDL이 허용하지 않는 `null`과 기타 코드는 상태별 집계에서 제외하고 월별 목록과 기록 개월 수에는 포함한다.
- N-20-5 기능 목록의 산식에는 분모가 12로 적혀 있다. 이번 승인 기준은 실제 기록이 있는 달 수다.

## 바뀐 파일

| 파일 | 변경 내용 |
|---|---|
| `MemberFinancialHealthService.java`, `FinancialHealthBaseResponse.java` | 기관 연동 공과금 집계 및 응답 필드 추가 |
| `FinancialHealthMapper.java`, `FinancialHealthMapper.xml` | 회원별 기관 연동 공과금의 달력 12개월 조회 |
| `MemberFinancialHealthServiceTest.java`, `FinancialHealthMapperIT.java` | 납부 상태별 집계, 빈 달·빈 기록, 출처 필터와 달력 12개월 경계 검증 |

## DB·API 변경

- DB: 기존 `USER_UTILITY_PAYMENT` 테이블을 조회한다.
- API: `GET /api/members/me/financial-health`에 `utilityPayment`를 추가했다. 연동 기록이 없으면 `null`이다.
- 영향을 받는 기능·팀원: 경환 담당 자산·부채 건전성 화면.

## 확인

- 확인함: 검수 반영 후 Maven Wrapper로 `MemberFinancialHealthServiceTest` 10개 통과. H2 Oracle 호환 모드에서 MyBatis 매퍼의 달력 12개월 경계, 빈 달, 청구월 순서, 회원·출처 필터와 빈 목록을 확인했다.
- 확인함: 검수 반영 전 Maven Wrapper로 `MemberFinanceControllerTest` 16개 통과.
- 확인 못 함: `FinancialHealthMapperIT`는 로컬 Oracle 접속 계정의 `CREATE SESSION` 권한 부족(`ORA-01045`)으로 실행하지 못했다.
