11/06 확정 UI 데모(「Avenue 기능 데모 v2」)를 기준으로 A팀 화면을 고친다. 데모 파일은 저장소에 올리지 않는다.
- 진행 순서: ① 화면 틀·헤더 ② 로그인 ③ 회원가입 ④ 찾기 ⑤ 직군 선택·데이터 입력 ⑥ 마이 페이지. 단계마다 커밋한다.
- 기준
  - 화면·흐름은 데모를 따른다. 명세와 다른 곳은 담당자(JWC)가 항목별로 정했다.
  - 우선순위 P0~P2만 1차에 한다. 미정·P3는 2차로 넘긴다.
  - CSS는 넣지 않는다. 기능·문구·흐름만 맞춘다.

## ① 화면 틀·헤더·접근 규칙 (N-08-1, N-01-2)

### 무엇을, 왜 바꿨나
- **주 메뉴 노출:** 사용자 주 메뉴는 직군을 고르고 점수가 나온 뒤에만 보인다. 직군 선택·데이터 입력 중에는 헤더 버튼만 보인다. 관리자 탭은 늘 보인다.
- **점수가 필요한 화면:** 신용 리포트·자산·부채 건전성·시나리오 테스트·현금흐름·소득 변동성·상권 분석·신용케어 시뮬레이터는 점수가 없으면 데이터 입력으로 보낸다.
  - 대출 상품·비교 분석·신용 라운지·마이 페이지·데이터 입력은 점수 없이도 열린다.
- **역할이 다른 화면:** `/forbidden` 대신 그 계정의 첫 화면으로 보낸다.
  - 관리자가 사용자 화면에 들어가면 모형 성능 비교로 간다.
  - 사용자가 관리자 화면에 들어가면 신용 리포트로 간다. 점수가 없으면 데이터 입력, 직군이 없으면 직군 선택으로 간다.
- **헤더**
  - 사용자: [알림]·[마이 페이지]·[로그아웃]. 이름·직군 배지는 없앴다.
  - 관리자: 로고 "Avenue Admin", '관리자' 칩, [로그아웃].
  - [마이 페이지]는 현재 위치 표시가 되는 링크로 바꿨다.
