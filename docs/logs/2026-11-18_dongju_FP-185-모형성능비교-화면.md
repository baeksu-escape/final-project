## DB·API 변경
- DB: 없음
- API(새 응답 필드 제안, 아직 서버 없음):
  - ADM-01 `GET /api/admin/model-performance?group=ALL|LEGACY|THIN_FILE&cutoff=550~750`
    → `{ group, cutoff, sampleCount, legacy: { modelVersion, auc, accuracy, misclassCost, goodRejectRate, badApproveRate, approvalRate }, alternative: { 같은 필드 }, byJob: [{ jobType, sampleCount, legacyGoodRejectRate, alternativeGoodRejectRate }] }`

## 11/19 B조 평가 표(MODEL_EVAL_SAMPLE)에 맞춰 수정
- **배경:** B조(altrongg, FP-235)가 평가 데이터를 DB 표 `MODEL_EVAL_SAMPLE`로 주기로 했다. 3,085행 = LEGACY VALID 1,800 + THINFILE 노출 1인 TRAIN 1,057 + VALID 228. 열은 라벨 2개, 라벨별 기존·대안 점수 4개, `GROUP_CODE` LEGACY/THINFILE, 직군 서비스 코드다. 위 「다음 사람이 알아야 할 것」의 TEST 표본·`ASSESSMENT` 기준은 이 표로 대신한다.
- **동주 결정**
  - 컷오프 **600~800점, 기본 700**: 실제 점수 중앙값이 약 700이고, 씬파일은 750점 초과가 33~37%라 550~750이면 위쪽이 잘린다(B조 제안).
  - **'전체' 집단 제외**: 두 집단은 정답 라벨 생성 방식이 달라 합치면 틀린 비교가 된다(B조 요청). 집단 코드는 표와 같게 `THIN_FILE` → `THINFILE`.
  - 비교 라벨(연체 / 비금융 효과) 선택 추가, 기본은 연체 라벨. 두 모형을 같은 정답으로 비교한다(정의서 C20).
- **화면 표시(B조 요청 반영)**
  - 씬파일은 "기존 집단으로 학습한 모델을 적용한 결과" 안내를 띄운다.
  - 표본 칩은 LEGACY "검증(VALID) 표본", THINFILE "기존 집단 학습 모델 적용(TRAIN+VALID)"으로 나누고 불량 수를 함께 보여 준다.
  - 머리 문구에 "합성 데이터 기준이며 실제 개선을 뜻하지 않습니다"를 넣었다.
  - AUC 옆에 출처를 붙인다(LEGACY "5개 시드 평균", THINFILE "시드 1개 값").
  - ROC 곡선에서는 AUC 숫자를 뺐다. 곡선은 시드 1개 표로 그리고 표의 AUC는 5개 시드 평균이라, 한 화면에 다른 AUC가 보이지 않게 하려는 것이다.
  - 직군별 막대에 표본·불량 수를 붙였다.

## 11/20 실제 API(FP-184)에 맞춘 화면 수정
- 서버 ADM-01·02(FP-184, 별도 PR)가 위 제안안 그대로 구현됐다. 서버 내용은 `2026-11-20_dongju_FP-184-모형성능비교-API.md`에 있다. 이 화면 PR은 서버 없이도 mock 모드로 동작한다.
- **% 단위**: API README 3장 규칙("비율은 % 소수 둘째 자리")에 맞춰 비율·ROC 좌표를 0~1에서 %로 바꿨다. AUC는 확률이라 0~1 그대로다. `formatRate`·표 %p 차이(0.05%p 미만은 '나빠짐'으로 치지 않음)·ROC 그림(%를 100으로 나눠 그림)·mock 값을 % 기준으로 고쳤다.
- **표시 오류 수정**: 직군별 막대에 %가 두 번 붙던 문제("12.3%%"). `formatRate`의 %와 CompareBar `unit`의 %가 겹쳤다.
- **ROC 컷오프 점(동주 요청, 명세 N-25-3에 없는 추가 표시)**: 지금 컷오프 위치를 곡선마다 점으로 찍는다. ADM-02 점은 기준 점수 0, 10, …, 1010 순서라 `컷오프/10`번째 점을 쓴다. mock ROC도 같은 102점으로 바꿨다. 안내 문구에 "점은 지금 컷오프(…점)의 위치입니다." 추가.
- **ROC 색(11/20 피드백: 두 선 구분)**: 선·점·범례 글자 기존 `--mut2`, 대안 `--vio2`, 기준 점선 `--mut`. tokens 변수만 썼고 새 CSS는 없다.
- `frontend/README.md` 화면 상태 표를 "화면 완료(FP-185), API는 FP-184"로 고쳤다.
- **바뀐 파일**: `modelPerformanceCodes.js`, `api/modelPerformanceApi.js`, `pages/ModelPerformancePage.jsx`, `components/ModelMetricTable.jsx`·`RocCurveChart.jsx`·`JobRejectBars.jsx`, `mocks/modelPerformanceMockHandlers.js`, `frontend/README.md`
- **확인**: `npm run lint` 오류 0, `npm run build` 성공. 로컬 Oracle + FP-184 서버로 화면 확인(동주 11/20: LEGACY·연체 라벨 1,800명·불량 174명, AUC 0.605 / 0.599, 컷오프 이동 시 표·막대·ROC 점 갱신).
