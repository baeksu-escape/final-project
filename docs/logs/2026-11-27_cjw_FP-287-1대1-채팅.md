- **날짜:** 2026-11-27
- **작성자:** 재욱 / Claude Code
- **브랜치:** `feature-B/FP-287-admin-chat`
- **관련 N-ID:** N-07-1~6
- **관련 결정:** decisions.md 1-5 「1:1 채팅」

## 무엇을, 왜 바꿨나
- v3에서 지운 N-07을 2차 개발로 다시 만든다. 저장·조회는 REST, 새 메시지 알림은 웹소켓이다.
- 웹소켓은 방 번호 신호만 보낸다. 본문은 REST로 읽어 기존 권한·계정 상태 검사를 그대로 받는다.
- 알림 브랜치(FP-300)와 겹치는 `AppHeader.jsx`·`AppRoutes.jsx`·API 정의서는 그 병합 뒤에 고친다. **지금은 화면으로 들어가는 길이 없다.**

| `features.md`, `decisions.md`, `api_spec_b.md`, SQL README, `backend/README.md` | 명세·결정·API·안내 추가 |

## DB·API 변경
- DB: `CHAT_ROOM`, `CHAT_MESSAGE`, 인덱스 `IX_CHM_ROOM`. 기존 표는 바꾸지 않았다.
- API: CHAT-01~09, 웹소켓 `/ws/chat` (`api_spec_b.md` 10장). 새 오류 code `CHAT_ROOM_NOT_FOUND`, `MEMBER_WITHDRAWN`.
- 영향을 받는 기능·팀원: DB 담당(적용 SQL), 프론트 담당(`chat.css`), A팀 알림(헤더·라우트 같은 파일), 범영(API 정의서 새 절).

## 확인
- 확인함: `backend` `./mvnw test` 634개 통과(채팅 27개 포함). `dummy_db/tools/tests` `python -m unittest` 56개 실행, 실패 0·건너뜀 3. `frontend` `npm run lint` 오류 없음, `npm run build` 성공.
