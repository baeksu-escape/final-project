# 더미 DB 시드 생성기를 DDL v0.3.1 확정본(47개 표)에 맞춤

- **날짜:** 2026-11-11
- **작성자:** 경환 / Claude Code
- **브랜치:** `KGH_Work`
- **관련 N-ID:** N-02-4, N-05-6
- **관련 결정:** D-05, DDL v0.3.1 머리말 E2·U1·U2·U3·S1

## 무엇을, 왜 바꿨나
- 범영 님이 DDL v0.3.1을 서비스 DB 배포용 확정본으로 정해, 저장소 DDL을 그 파일과 바이트까지 같게 바꿨다. 폴더 이름 `v0_2`는 그대로 두었다.
- 시드 생성기를 47개 표에 맞췄다. 공과금 표를 채우고, `late` + 납부일 없음을 `UNPAID`로 바꾸고, 암호문 앞에 `v1:` 접두어를 붙인다.

## DB·API 변경
- DB: 기준 DDL을 v0.3.1(47개 표)로 교체. 새 표 `USER_UTILITY_PAYMENT`, CHECK `CK_UTP_PAID_DATE`·`CK_UUP_PAID_DATE`. 시드는 동의 항목 `utility`/`UTILITY_BILL`이 늘어 `USER_CONSENT` 3,600 → 4,000행.
- API: 없음
- 영향을 받는 기능·팀원: A팀 Spring(UNPAID 변환, `v1:` 복호화), DB 담당

## 확인
- 확인함: `python -m unittest discover -s tests`(tools 폴더, `AVENUE_TEST_SERVICE_DUMMY` 설정, 테스트 키) 19개 통과. 400명 생성 결과 47개 표, `USER_UTILITY_PAYMENT` 3,816행(LATE 32·UNPAID 2), 통신비 3,816행(LATE 15·UNPAID 0). 생성한 `00`·`99`가 저장소 파일과 같음. 데이터 패키지 manifest 87개 해시 일치.
- 확인 못 함: 실제 Oracle 적재·`99_check.sql` 실행.

## 추가: 팀 개발 키 시드·시연 계정 (같은 날)
- 회의 결정: 팀 개발 키 한 쌍을 저장소 밖(디스코드 비공개 채널)으로 공유하고, 그 키로 만든 시드 SQL을 커밋한다. `bcrypt` 추가 승인.
- 바뀐 파일: `tools/gen_dev_keys.py`(새 파일, 저장소 밖에만 저장·덮어쓰기 거부·값 미출력), `tools/build_db_v02.py`(`--env-file`, 시연 계정 3명 `demo_employee`·`demo_self`·`demo_free`의 BCrypt `$2a$` cost 10 해시, `AVENUE_DEMO_PASSWORD` 필수), 테스트, `dummy_db/.env.example`(새 파일, 이름만), `v0_2/README.md`(키·시드 절차, run_all 규칙), `data_generation/requirements.txt`(`bcrypt==5.0.0`), `SERVICE_DUMMY_DATA.md`(`ASSESSMENT` 명시, 절 제목), `manifest.json`(해시 2개).
- DB: 구조 변경 없음. 시드에서 `APP_USER` 3행의 `LOGIN_ID`·`PASSWORD_HASH`가 바뀐다.
- 확인함: tools 테스트 26개 통과(400명 전체, 테스트 키·테스트 비밀번호). manifest 87개 일치.
- 확인 못 함: 실제 키로 시드 생성·커밋(사용자가 함), Spring 로그인 실제 검증, Oracle 적재.

## 추가: 관리자 시연 계정·원자적 쓰기 (같은 날)
- N-01-5: 관리자 시연 계정 `demo_admin`을 더미 회원과 별도의 새 행(USER_ID 401, `ROLE_ADMIN`, 직군·출생연도·휴대폰 NULL, 회원 데이터 행 없음)으로 추가했다. 비밀번호는 사용자 시연 계정과 같은 `AVENUE_DEMO_PASSWORD`. `APP_USER` 시드 400 → 401행. `DIM_ROLE`의 `ROLE_ADMIN` 기준 행이 DDL에 있는 것을 확인했다.
- 검수 지적 반영: 생성기가 모든 파일을 임시 파일로 쓴 뒤 한꺼번에 교체하고, 실패하면 기존 파일을 되돌린다. `SERVICE_DUMMY_DATA.md`의 옛 설명(합의 전 초안, env 파일 미지원, 커밋 키 미정)을 고쳤다(manifest 해시 1개). README 명령을 `python -I -X utf8`로 바꿨다.
- 확인함: tools 테스트 29개 중 28개 통과. 실패 1개는 저장소의 `99_check.sql`이 관리자 추가 전 생성본(`APP_USER` 400)이라 생기는 차이이며, 시드를 다시 생성하면 맞는다. manifest 87개 일치.
- 확인 못 함: 실제 키로 재생성(사용자가 함), Spring 관리자 로그인·Oracle 적재.
