# 시드 대출 종류 v3.6.1 반영·생성 패키지 manifest·LF 고정

- **날짜:** 2026-11-13
- **작성자:** 경환 / Codex
- **브랜치:** `KGH_Work`
- **관련 N-ID:** N-05-3
- **관련 결정:** D-27(대출 입력 항목 미정)

## 무엇을, 왜 바꿨나
- 11/12 시드는 v3.6.1 이전 원천으로 생성돼 대출 종류·금리 방식이 모두 OTHER·UNKNOWN이었다. 11/12 로그와 커밋 메시지의 반영 내용이 실제 시드와 달랐다.
- 사용자가 승인한 v3.6.1 원천의 13번 대출 시드로 교체했다.
- Windows 체크아웃에서 생성 패키지가 CRLF로 바뀌어 검증이 실패해, 이 폴더에만 LF 고정 설정을 추가했다. 커밋 후 각자 `git rm -r --cached fastapi_server/data_generation` → `git checkout -- fastapi_server/data_generation`로 한 번 다시 받는다.
