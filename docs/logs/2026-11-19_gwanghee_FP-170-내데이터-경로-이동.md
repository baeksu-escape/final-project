## 무엇을, 왜 바꿨나
- SIM-01·02, DIAG-07-1·08-1·09는 로그인 회원의 저장 데이터를 읽는 API인데 `/api/simulation`·`/api/diagnosis`(임시 개방 경로)에 있었다. 그래서 컨트롤러가 직접 401을 내고 있었다.
- 팀 공통 규칙대로 `/api/members/me/**`로 옮겼다. 이제 보안 설정이 로그인을 먼저 확인한다(토큰 없음 401, 관리자 403). 옛 경로는 같은 PR에서 지웠다(우찬 님 요청).
- 경환 님 요청 2건을 넣었다.
  - SIM-01 응답에 감점 요인 상위 3개(`topReductionFactors`)를 추가했다. 출발 평가의 `ASSESSMENT_FACTOR`에서 고르고, 모델은 부르지 않는다.
  - DIAG-08-1 응답에 기준값 3개를 추가했다.

## DB·API 변경
- DB: 없음 (기존 `selectFactors`·`selectLatestFixedExpense`를 다시 씀)
- API:
  | ID | 옛 경로 (삭제) | 새 경로 |
  |---|---|---|
  | SIM-01 | `GET /api/simulation/credit-care/base` | `GET /api/members/me/credit-care-base` |
  | SIM-02 | `POST /api/simulation/credit-care/recalculate` | `POST /api/members/me/credit-care-recalculate` |
  | DIAG-07-1 | `GET /api/diagnosis/income-volatility` | `GET /api/members/me/income-volatility` |
  | DIAG-08-1 | `GET /api/diagnosis/cash-flow/forecast` | `GET /api/members/me/cash-flow-forecast` |
  | DIAG-09 | `POST /api/diagnosis/cash-flow/expected-score` | `POST /api/members/me/cash-flow-expected-score` |
  - 응답 필드 추가: SIM-01 `topReductionFactors`, DIAG-08-1 `baseFixedExpenseAmount`·`baseOtherExpenseAmount`·`baseMonthlyLoanPayment`
  - 새 경로는 `ROLE_USER` 전용이다. 관리자 토큰이면 403 `FORBIDDEN`이다.
  - 같은 주소의 POST(DIAG-07·08)는 그대로다. 그 주소로 GET을 보내면 405다.
- 영향을 받는 기능·팀원
  - 경환 님: 시뮬레이터·현금흐름·소득 변동성 화면. 상수 이름은 그대로이고 값만 바뀐다. `KGH_Work`와 상수 줄이 충돌할 수 있다(경환 님이 광희 님 것을 남기기로 함).
  - 우찬 님: `api_definition.md`·`api_spec_b.md`의 옛 경로를 문서 PR로 정리한다.
  - 범영 님: 정의서 상태 확인.
