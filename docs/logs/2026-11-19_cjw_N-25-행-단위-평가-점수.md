# N-25 모형 비교 화면용 행 단위 평가 점수(VALID) 내보내기 스크립트

- **날짜:** 2026-11-19
- **작성자:** 최재욱(B팀 모델·정의서 담당) / Claude Code
- **브랜치:** `feature-B/FP-216-eval-scores-export` (FP-216 후속, Jira 키가 정해지면 바꿉니다)
- **관련 N-ID:** N-25 모형 성능 비교
- **관련 결정:** 정의서 10장 C20(같은 라벨끼리 비교), 11/19 동주·재욱(컷오프 550~750 지표 6개·ROC·직군별 오거절률을 FP-184 API가 행 데이터로 계산, 두 라벨 모두 필요, 표본은 VALID), 11/19 DDL·공용 md는 재욱 작업과 연계되면 직접 수정 가능

## 무엇을, 왜 바꿨나
- 관리자 모형 비교 화면(FP-185)과 API(FP-184)는 컷오프를 움직이며 지표 6개와 직군별 오거절률, ROC를 보여 준다. AUC 평균 하나로는 만들 수 없어서 VALID 행마다 점수와 정답이 필요하다.
- `training/export_eval_scores.py`를 추가했다. 기존 집단 TRAIN으로 라벨마다 두 모델(기존 18개·대안 38개)을 새로 학습하고(시드 11, 같은 라벨끼리 비교하는 정의서 C20 방식), 평가 행마다 점수 4개와 정답 라벨 2개를 CSV(`eval_scores.csv`)로 낸다. 기존 집단은 VALID 1,800행만, 씬파일 집단은 이 모델들이 학습하지 않은 집단이라 TRAIN+VALID 1,285행(총 3,085행)을 쓴다. 씬파일 VALID 228행만으로는 양성이 연체 22건·비금융 효과 14건뿐이라 지표가 흔들려서 TRAIN 행까지 넣었다(누수 없음, 11/19 재욱 결정, `--thinfile-valid-only`로 되돌릴 수 있음). 씬파일은 정의서 5장대로 `eval_future_credit_exposure = 1`인 고객만 넣는다(TRAIN+VALID 2,041행 중 0인 756행은 라벨이 항상 0이라 제외). TEST는 읽자마자 버리고 파일에 넣지 않는다(최종 평가 FP-144 때 같은 스크립트로 따로 만든다).
- 서버에 올린 모델(`legacy.joblib`, `alternative.joblib`)과 같은 설정이라 두 열(`score_legacy_delinq`, `score_alt_nonfin`)은 서버 모델 그대로이고, 스크립트가 점수가 같은지 확인해 설명 파일에 적는다. 나머지 두 열은 비교용 실험 모델이다.

## 확인
- 확인함: FastAPI 테스트 130개 통과(새 14개 포함). 실제 학습 데이터로 실행해 3,085행(기존 집단 VALID 1,800 + 씬파일 TRAIN 1,057 + VALID 228)과 직군별 건수가 학습 표 집계와 같고(씬파일은 노출 1인 1,285행: 프리랜서 441 / 자영업자 422 / 급여소득자 422, 양성 연체 122·비금융 효과 117), 점수 열별 VALID AUC가 정의서 C20·`METRICS_JSON`의 시드 11 값과 같음(연체 라벨 기존 0.6062, 대안 0.6183, 비금융 효과 라벨 기존 0.6085, 대안 0.6564, 정수 점수 기준이라 확률 기준 0.6064·0.6565와 소수 넷째 자리가 다름). 서버 모델 파일 두 개와 점수가 같음. 학습 표 SHA 앞 8자리 `79511b5d`(기존 집단)·`bb10ebb4`(thinfile).
- 확인 못 함: 동주 API에서 이 파일을 읽어 지표를 계산하는 모습, DB 적재 방식, 다른 PC 재현.

## 다음 사람이 알아야 할 것
- 씬파일은 기존 집단으로 학습한 모델을 적용한 결과다. 씬파일을 학습에 쓰는 모델이 생기면 TRAIN 행이 누수가 되므로 `--thinfile-valid-only`로 다시 만든다. 직군별로는 양성이 적어 지표가 흔들리므로 화면에 건수와 함께 보여 주는 편이 안전하다.
- 1,285행 평가 결과(시드 11, 정수 점수): 연체 라벨 기존 0.5712 / 대안 0.5654(대안 데이터 효과를 넣지 않은 설계라 정상), 비금융 효과 라벨 기존 0.5598 / 대안 0.6148(+0.055, 경환 님 교차검증 +0.067과 방향이 같음).
- 연체 라벨에서 기존 집단의 대안 모델 AUC는 시드 11(0.6183)이 5개 시드 중 최고이고 평균은 0.5991이다. 화면의 AUC는 `METRICS_JSON` 5개 시드 평균을 쓰고 이 파일은 컷오프별 지표·ROC에 쓴다.
- 행 데이터의 AUC는 시드 하나(11)의 값이라 `METRICS_JSON`의 5개 시드 평균과 조금 다르다.
- 모델을 다시 학습하면(새 MODEL_VERSION) 이 파일도 다시 만들어 공유한다.
- CSV와 설명 파일은 Git에 올리지 않고 `#파일공유`로 전달한다(`.gitignore`).
- 로그 파일명의 작성자 약어 `cjw`는 제안이다.
