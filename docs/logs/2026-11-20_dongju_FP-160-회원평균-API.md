# FP-160 N-15 같은 직군·연령대 회원 평균 API(DIAG-01) 추가

- **날짜:** 2026-11-20
- **작성자:** 동주 / Claude Code
- **브랜치:** `feature-C/FP-160-peerBenchmark`
- **관련 N-ID:** N-15-2, N-15-3
- **관련 결정:** 11/19 팀 결정(N-15 비교 기준 = 서비스 회원 평균), 11/20 동주 결정(직군 평균·연령대 평균 둘 다, 경로는 광희 님 API처럼 `/api/members/me/…`)

## 무엇을, 왜 바꿨나
- 경환 님 자산·부채 화면의 "같은 직군 평균과 비교" 카드(N-15-3)에 붙일 API가 없었다. 공공통계에는 프리랜서 구분이 없어 11/19에 회원 표 평균으로 바꾸기로 했다.
- `GET /api/members/me/peer-benchmark`(DIAG-01)를 새로 만들었다. 로그인 회원의 직군·연령대와 같은 직군 평균·같은 연령대 평균(연소득·총자산·총부채)을 돌려준다. 5명 미만 그룹은 금액을 null로 준다.
- 연소득은 N-20-3 공유 함수(`FinancialHealthCalculator.calculateAnnualIncome`), 연령대는 평가 저장과 같은 `ScoreCalculationService.ageBandCode`를 써서 다른 기능과 숫자가 어긋나지 않게 했다.

## DB·API 변경
- DB: 없음(읽기만). `APP_USER`, `USER_INCOME_MONTH`, `USER_ASSET_SNAPSHOT`, `USER_LOAN`
- API: 새 경로 `GET /api/members/me/peer-benchmark` (DIAG-01). 응답 `{ workerTypeCode, ageBandCode, sameWorkerType{memberCount, annualIncomeAmount, totalAssetAmount, totalDebtAmount}, sameAgeBand{같은 필드} }`
  - 정의서(`api_definition.md`)는 범영 님 관리라 고치지 않았다. 반영 요청: DIAG-01 경로 `/api/finance/peer-benchmark` → `/api/members/me/peer-benchmark`, 원천 회원 표 4개, 담당 동주(FP-160) / DIAG-02 `/all`은 쓰는 화면이 없어 만들지 않음
- 영향을 받는 기능·팀원: 경환(자산·부채 화면 N-15-3 연결), 범영(정의서 반영, `ageBandCode` public 변경 확인)

## 확인
- 확인함: `./mvnw test -Dtest='PeerBenchmark*'` — 서비스 6개·컨트롤러 4개 통과, DB 시험 2개는 건너뜀(정상).
- 확인함: `./mvnw test` 전체 — 425개 실행, 실패 0.
- 확인 못 함: `PeerBenchmarkMapperIT`(-Ddb.it=true) — 터미널에 실행 환경 변수(`AVENUE_JWT_SECRET` 등)가 없어 컨텍스트가 뜨지 않았다. IDE 실행 설정(env 연결)에서 동주가 실행해야 한다. 실제 Spring 실행 후 API 호출도 아직이다.
- 시드 확인: 더미 회원 400명 모두 자산 기준월 = 가장 늦은 소득월이라 "기준월 = 가장 늦은 소득월" 규칙으로 자산이 빠지는 회원이 없다.
