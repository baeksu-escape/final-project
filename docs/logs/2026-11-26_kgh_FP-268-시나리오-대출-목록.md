# FP-268 시나리오 기준값 응답에 대출 목록 추가

- **날짜:** 2026-11-26

- **관련 N-ID:** N-17-1
- **관련 결정:** 광희 확인(11/26)

## 무엇을, 왜 바꿨나
- DIAG-04 `scenario-base` 응답에 기준월의 전체 대출 목록과 잔액을 추가한다. 남은 기간은 포함하지 않는다. 시나리오 화면은 이 목록을 따로 보여 주지 않고 "보유 대출 전체 보기" 링크(자산·부채 화면)만 두며, `loanItems`는 API에 남겨 둔다.
- 월 상환액은 같은 기준월 대출 목록의 월 원리금을 합산해, 응답 목록과 합계가 일치하도록 한다. 대출이 없으면 빈 목록과 0원을 반환한다.
- 재계산 응답에도 현재 기준월 대출 `loanItems`를 포함하고 현재 월 상환액을 그 목록 합으로 맞췄다. 기존 DTO 생성자는 기존 호출부 호환을 위해 유지했다.
- 광희 님 쉬운 화면 시안(베스트·워스트 버튼, [예상 시나리오 계산하기])을 반영하고, 초기화하면 변화 0 조건으로 바로 다시 계산한다.
- 변동금리 대출 잔액·금리·월 원리금도 같은 `loanItems`에서 `VARIABLE` 항목만 골라 쓰며, `UNKNOWN`은 금리 변경 계산에서 제외한다.
