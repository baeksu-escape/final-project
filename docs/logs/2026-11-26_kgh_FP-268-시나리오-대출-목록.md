# FP-268 시나리오 기준값 응답에 대출 목록 추가

- **날짜:** 2026-11-26
- **작성자:** kgh / Codex
- **브랜치:** KGH_Work에서 작업, PR 브랜치 feature-A/FP-268-scenario-feedback
- **관련 N-ID:** N-17-1
- **관련 결정:** 경환 승인, 광희 님께 확인 요청 중

## 무엇을, 왜 바꿨나
- DIAG-04 `scenario-base` 응답에 기준월의 전체 대출 목록을 추가한다. 항목의 종류·연 금리·금리 방식·월 원리금을 화면에서 확인할 수 있다.
- 월 상환액은 같은 기준월 대출 목록의 월 원리금을 합산해, 응답 목록과 합계가 일치하도록 한다. 대출이 없으면 빈 목록과 0원을 반환한다.
