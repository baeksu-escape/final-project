## 무엇을, 왜 바꿨나
- 서비스는 소득만 12개월(급여소득자는 1개월 × 12), 지출은 평균 월 지출, 상환은 현재 월 원리금 하나를 받는다. 학습도 같은 정의로 맞추려고 `input_features_12m.csv` 뒤쪽에 서비스 정의 9열을 붙이고, 대체된 기존 12개월 6열은 `compatibility_only`로 내렸다. 기존 열 값·이상치 기록은 그대로다.
- 원천의 급여소득자 월 소득이 출렁여(CV 평균 0.056) 서비스 정의 열에서만 기준월(2026-08, 급여 기준월은 팀 확인 전 임시) 소득을 12개월로 펼쳤다.
- 학습·검증·시험 구분 `data_split`(TRAIN/VALID/TEST 70/15/15, 고객 ID 단위, 직군 × 부도 층화, seed 20261114)을 추가하고 모델 표 `dataset` 뒤에 `role = split`으로 넣었다.
- 사용자 추가 지시: `telecom_late_months`·`utility_late_months` 설명의 "현 버전 0 또는 1"을 "0~12, 실제 생성 분포 0~5"로 정정했다.
