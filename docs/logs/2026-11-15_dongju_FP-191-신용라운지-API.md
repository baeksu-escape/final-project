# FP-191 신용 라운지 백엔드 API (글·댓글·신고·관리자 신고 처리·설정)

- **날짜:** 2026-11-15
- **작성자:** 동주 / Claude Code
- **브랜치:** `feature-C/FP-191-community`
- **관련 N-ID:** N-06-1~6, N-33-1·2, N-34-1~3
- **관련 결정:** D-10(신고 처리), D-25(알림은 빈 테이블만), 탈퇴 회원 글 표시(11/12)

## 무엇을, 왜 바꿨나
- 신용 라운지 1단계 백엔드(FP-192 글·댓글, FP-193 신고·관리자 처리)를 만들었다. 화면(FP-194·206)은 2단계에서 만든다.
- 경로는 범영님 API 정의서 v0.2 초안의 COMM-01~07, ADM-11~14를 따랐다. DB 테이블은 DDL v0.3.2에 이미 있어서 바꾸지 않았다.
- 명세에 없던 내 글 수정·삭제(COMM-04·05)를 넣기로 해서(동주 11/15) features.md에 N-06-5·6을 추가했다.

## DB·API 변경
- DB: 없음 (BOARD_POST, BOARD_COMMENT, BOARD_POST_LOG, CONTENT_REPORT, APP_SETTING 사용)
- API (모두 새로 추가)
  - `GET /api/board/posts?page&size&keyword`, `GET /api/board/posts/{postId}` (상세 + 댓글)
  - `POST /api/board/posts`, `PUT`·`DELETE /api/board/posts/{postId}` (내 글만)
  - `GET`·`POST /api/board/posts/{postId}/comments`
  - `POST /api/reports` `{targetType, targetId, reasonCode, detailText}`
  - `GET /api/admin/reports?status&reason&from&to`, `GET /api/admin/reports/{reportId}`, `PATCH /api/admin/reports/{reportId}` `{resultCode, memo}`
  - `GET /api/admin/settings`, `PUT /api/admin/settings` `{settingKey, value}`
- 영향을 받는 기능·팀원
  - 범영(API 정의서): 아래 "정의서와 다른 점"을 반영해 주세요.
  - ADM-14를 쓸 다른 담당자(챗봇 횟수 등): `EditableSettings.RULES`에 한 줄을 추가해서 쓰면 됩니다.

## 확인
- 확인함: `./mvnw test` 결과 131개 통과(새 테스트 41개 + 기존 90개). develop(PR #52·#53 FP-80) 병합 뒤 240개 통과. FP-80의 `/api/admin/**` 비밀번호 변경 확인 인터셉터 때문에 계약 테스트에 `AdminAccountMapper` mock을 추가했다. 신고 규칙(본인 글, 중복, 하루 3번, 기타만 상세, 기준 5건 자동 숨김, 관리자가 바꾼 기준)과 처리(숨김 유지·삭제·반려, 이미 처리됨), 권한(비로그인 401, 일반 사용자의 관리자 API 403)을 테스트한다.
- 확인 못 함: 테스트 DB는 H2라 SQL을 실제로 실행하지 않았다(매퍼는 mock). Oracle에서 글 작성 → 같은 글 5번 신고(다른 계정) → 자동 숨김 → 관리자 반려 흐름을 직접 확인해야 한다.

## 다음 사람이 알아야 할 것
- **정의서와 다른 점**
  - ADM-13은 신고 한 건이 아니라 **대상 단위**로 처리한다. 같은 글·댓글의 미처리 신고가 한 번에 같은 결과로 닫힌다(N-34-1 묶음 목록 기준).
  - ADM-14는 범용 경로지만, 지금 바꿀 수 있는 키는 `REPORT_AUTO_HIDE_COUNT`(3~10) 하나다. 목록에 없는 키는 400 `UNKNOWN_SETTING`.
  - 정의서의 담당 표기 FP-168은 지금 Jira의 FP-191~194·206이다.
- **알림은 만들지 않았다.** N-34 UI의 "처리하면 신고자·작성자에게 알림"은 D-25(알림 생성·발송 기능 없음)에 따라 뺐다.
- 자동 숨김은 미처리 신고(RECEIVED·IN_REVIEW)만 센다. 반려 후에는 0건부터 다시 센다. 댓글에는 기록 표가 없어 상태만 바뀐다.
- 숨김 글·댓글은 응답에서 제목·내용이 null이고 `hidden: true`다. 검색은 보이는 글에서만 한다.
- 작성자 닉네임은 탈퇴 회원이면 '탈퇴한 회원', 관리자 상세의 신고자 닉네임은 가린 값(`PiiMasking.name`)이다.
