## 무엇을, 왜 바꿨나

- 자산·부채 기준값 DIAG-03-1 `GET /api/members/me/financial-health`(광희 FP-239, PR #125)와 같은 직군 평균 DIAG-01 `GET /api/members/me/peer-benchmark`의 `sameWorkerType`(동주 FP-160, PR #120)을 병렬 조회한다. 미입력은 null로 유지한다(O-15).
- [값 바꿔 보기]는 DIAG-03 계산 API를 쓰며 연 원리금 추정에는 화면 시연 계산 `previewAssetDebtMock`을 쓴다. 계산 중·오류 안내는 입력 카드에 표시한다. 평균 안내는 “같은 직군 회원 중 입력한 회원의 평균입니다”다.
- 현금흐름 전망 DIAG-08-1과 예상 점수 DIAG-09를 서버에 연결하고 기준값 3개(`baseFixedExpenseAmount`·`baseOtherExpenseAmount`·`baseMonthlyLoanPayment`, PR #103)를 쓴다. 첫 예측 뒤에는 [예측 다시 하기]로 요청해 서버·모델 부하를 줄인다(N-21-8).
- 납부 밀림이 점수 계산에 반영되면 “최근 1년 30일 이상 연체 1회 추가로 가정”을 고정된 한 줄에 붉게 표시한다(D-32, PR #125·#126).
