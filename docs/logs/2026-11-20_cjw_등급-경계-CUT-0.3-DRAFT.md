# 모델 0.2 점수 분포로 다시 계산한 등급 구간 CUT-0.3(DRAFT) DB 기준 데이터 추가

- **날짜:** 2026-11-20
- **작성자:** 최재욱(B팀 모델·정의서 담당) / Claude Code
- **브랜치:** `feature-B/FP-139-cutoff-cut-0-3` (Jira FP-139 후속)
- **관련 N-ID:** N-04(등급 구간), N-12·N-18·N-25(등급 표시·비교)
- **관련 결정:** `decisions.md` D-01, 정의서 10장 C24·C25·C27, 11/20 사용자 결정(새 버전 `CUT-0.3` 추가, `CUT-0.2`는 고치지 않음), 11/19 DDL·공용 md는 재욱 작업과 연계되면 직접 수정 가능

## 무엇을, 왜 바꿨나
- 11/20 모델을 `LGBM-BASE-0.2`(단조 제약 후보 B, C25)로 채택하면서 점수 분포가 조금 달라졌다. 11/19에 추가한 `CUT-0.2`(659/731)는 모델 0.1 분포 기준이라, 0.2 분포로 25/50/25를 다시 계산한 경계를 새 버전 `CUT-0.3`으로 DB에 넣어 두었다.
- 경계는 기존 집단 VALID 1,800행의 대안 모델 점수 p5/p25/중앙값/p75/p95 = 576/653/693/727/777에서 나온 **CAUTION 0부터 653, STANDARD 654부터 726, GOOD 727부터 1000**이다(0.1은 590/659/697/731/778). 이 경계의 비율(주의/보통/우수)은 대안 모델 25.6/48.7/25.7%, 기존 모델 28.5/56.4/15.1%다. 기존·대안 모델은 같은 경계를 쓴다(C18 제안).
- **DRAFT로만 넣었다.** ACTIVE는 계속 `CUT-0.1`(665·780)이고 `CUT-0.2`·`CUT-0.3`은 쓰이지 않는다. 어느 버전으로 언제 전환할지는 팀이 정한다. 그래서 화면, 점수 저장, 대출 상품 기준이 달라지지 않는다. 이미 병합된 `CUT-0.2` 행은 고치지 않았다.
