# 신용 리포트 점수 비교·SHAP 화면 추가

- **날짜:** 2026-11-12
- **작성자:** 경환 / Codex
- **브랜치:** `KGH_Work`
- **관련 N-ID:** N-12-1, N-12-6, N-14-2·3·4
- **관련 작업:** FP-88, FP-89 일부
- **관련 결정:** A-16(정렬·개선 미션 위치, 미정)

## 무엇을, 왜 바꿨나
- 기존·대안 모델의 점수와 등급, 피처 칩, 산출 불가 상태를 리포트에 표시한다.
- SHAP 기준점과 항목별 증감 점수·대안 데이터 여부를 보여 준다. 합성 mock으로 상태를 확인한다.
- 공통 라우터의 `/report`를 기존 자리 표시 화면에서 새 리포트로 연결했다. 사용자 승인을 받았다.

## DB·API 변경
- DB: 없음.
- API: 기존 RPT-02 초안의 `GET /api/report/me`를 호출한다. 서버 API는 변경하지 않았다. 모델별 칩과 지난번 대비 변화는 mock 임시 필드다.
- 영향을 받는 기능·팀원: 범영(RPT-02 응답), FP-89 담당자(SHAP·개선 미션).

## 확인
- 확인함: `frontend`에서 `npm run lint`, `npm run build` 통과. SHAP mock은 639 + 62 = 701이며 순위는 절댓값 내림차순이다.
- 사용자 요청서에 따르면 사용자가 `npm run dev`로 mock 시나리오 7개, 다크 테마와 모바일 화면을 확인했다.
- 확인 못 함: 실제 RPT-02 서버 연동. 이번 기록 작성 시 화면을 다시 실행하지 않았다.

## 다음 사람이 알아야 할 것
- 모델별 피처 칩 전체 목록, 배너의 지난번 대비 변화와 새 점수 판단 기준은 RPT-02에서 미정이다. 범영 님과 확인한다.
- SHAP 정렬 기준(A-16)과 N-14-5 개선 미션 위치는 미정이다.
- 부도 확률 N-12-7은 표시 여부가 미정이라 화면에 표시하지 않는다.
- 일괄 검토 메모: 공통 헤더에서 이름·직군이 붙어 보이고, 테마 전환 버튼이 없다. 담당자 확인이 필요하다.
