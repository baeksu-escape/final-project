# 신용 리포트 점수 비교·SHAP 화면 추가

- **날짜:** 2026-11-12
- **작성자:** 경환 / Codex
- **브랜치:** `feature-A/FP-88-credit-report`
- **관련 N-ID:** N-12-1, N-12-6, N-14-2·3·4
- **관련 작업:** FP-88, FP-89 일부
- **관련 결정:** SHAP 정렬 B안·개선 미션 바로가기 A안·새 점수 배너 기준(11/13 확정)

## 무엇을, 왜 바꿨나
- 기존·대안 모델의 점수와 등급, 피처 칩, 산출 불가 상태를 리포트에 표시한다.
- SHAP 기준점과 항목별 증감 점수·대안 데이터 여부를 보여 준다. 합성 mock으로 상태를 확인한다.
- 공통 라우터의 `/report`를 기존 자리 표시 화면에서 새 리포트로 연결했다. 사용자 승인을 받았다.
- 11/13: SHAP 항목을 올림·내림 묶음과 영향 크기순으로 정렬(같으면 서버 rank), 점수를 내린 시뮬레이션 가능 항목에 시뮬레이터 바로가기 추가, 새 점수 배너를 같은 평가를 처음 볼 때만 표시, 지난번 대비 변화를 MEM-06 `alternativeScoreChange`로 조회하고 임시 필드 `previousScoreDiff` 제거.

## DB·API 변경
- DB: 없음.
- API: 기존 RPT-02 초안의 `GET /api/report/me`와 MEM-06 `GET /api/members/me/diagnoses`를 호출한다. 서버 API는 변경하지 않았다. 모델별 칩만 mock 임시 필드다. MEM-06 mock은 우찬 님 PR #45에 있어 이 브랜치에는 등록하지 않았다.
- 영향을 받는 기능·팀원: 범영(RPT-02 응답), FP-89 담당자(SHAP·개선 미션).

## 확인
- 확인함: `frontend`에서 `npm run lint`, `npm run build` 통과. SHAP mock은 639 + 62 = 701이며 순위는 절댓값 내림차순이다.
- 사용자 요청서에 따르면 사용자가 `npm run dev`로 mock 시나리오 7개, 다크 테마와 모바일 화면을 확인했다.
- 11/13 수정분: `npm run lint` 통과(오류 0). diff 로직 검수.
