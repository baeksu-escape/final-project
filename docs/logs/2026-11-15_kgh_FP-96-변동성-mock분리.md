# FP-96 소득 변동성 계산을 mock으로 분리하고 화면은 API 결과만 표시

- **날짜:** 2026-11-15
- **작성자:** 경환 / Claude
- **브랜치:** `KGH_Work`
- **관련 N-ID:** N-22-3·4·5·6 (공유 계산 N-21-7·N-22-4)
- **관련 결정:** 팀 방향 — 정식 재무 계산은 광희 FP-203 백엔드 API 담당

## 무엇을, 왜 바꿨나
- 프론트 `utils/incomeStats.js`가 소득 변동성 지표를 직접 계산하던 것을 `mocks/incomeVolatilityMock.js`로 옮겨 mock 임시 계산임을 분명히 했다.
- `IncomeVolatilitySection`은 계산 함수를 부르지 않고 `getIncomeVolatility` API 함수 결과만 표시하도록 바꿨다. 화면 문구·12% 기준·통계 결과는 그대로다.
- FP-203 정식 API가 붙기 전까지 쓰는 임시 응답 모양과 adapter를 두었다. 경로·응답 계약은 아직 정해지지 않았다.

| `frontend/src/features/diagnosis/adapters/incomeVolatilityAdapter.js` | 신규 — 응답 형식 검사(NULL 유지, 형식 오류는 오류) |

## DB·API 변경
- DB: 없음
- API: 서버 경로 없음(미정). 프론트 함수 `getIncomeVolatility` 추가(mock 전용, 실모드는 명시 오류)
- 영향을 받는 기능·팀원: 광희(FP-203) — 정식 응답 계약이 정해지면 adapter만 맞추면 된다. FP-202 페이지 연결은 하지 않았다.
