## 무엇을, 왜 바꿨나

- 소득 변동성 DIAG-07-1 `GET /api/members/me/income-volatility`를 서버에 연결했다. `IncomeVolatilitySection`은 현금흐름 화면에서 API 응답의 변동성 지표와 소득 부족 달을 표시한다.
- `incomeVolatilityApi.js`가 `diagnosisApi.js`의 서버 호출 결과를 화면 형식으로 변환한다. mock 모드에서는 공통 mock 핸들러의 예시 응답을 사용한다.
- 로딩·오류와 다시 시도를 표시하고 회원·직군 전환이나 화면 이탈 시 늦은 응답을 무시한다.
