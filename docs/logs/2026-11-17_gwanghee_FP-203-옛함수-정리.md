- **관련 N-ID:** N-22-3, N-22-4, N-22-5, N-21-5, N-21-6, N-21-7

## 무엇을, 왜 바꿨나
- 코드 리뷰에서 지적한 FP-183 초기 함수를 정리했다.
  - 이 함수들은 `BigDecimal` 목록 입력에 `"Month 1"` 같은 이름표를 썼다.
  - 지금 API가 쓰는 함수(`MonthlyIncomeItem` 입력, 기준월 이름표)와 이름이 겹쳤다(`calculateVolatility` 2개).
  - API에서는 쓰지 않았다.
- 지운 함수와 DTO는 develop에도, 다른 팀원 브랜치에도 없고 광희 FP-183 계열 브랜치에서만 쓰였다. 그래서 팀 규칙 3-1(공유 함수 이름 유지)의 대상이 아니라고 판단했다.
- 지금 진단 함수가 옛 함수에서 받아 오던 평균·변동계수·0원 달 수 계산은 비공개 도우미(`summarizeIncomes`)로 옮겼다. 반올림 단계를 그대로 유지해 결과 숫자가 같다.
