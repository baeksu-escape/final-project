## 무엇을, 왜 바꿨나
- `drop_unused_market_tables.sql`의 `ORDER BY step_no`를 `ORDER BY 1`로 바꿨다.
- 팀원이 공용 DB에서 실행하다 이 줄에서 실패했다고 보고했다. 받은 오류 원문:
  - `ORA-06550: 줄 10, 열 18:` `PL/SQL: ORA-00904: "STEP_NO": 부적합한 식별자`
  - `ORA-06550: 줄 5, 열 9:` `PL/SQL: SQL Statement ignored`
- 원인: PL/SQL 커서 FOR 루프 안의 UNION ALL 쿼리에서 `ORDER BY step_no`처럼 별명을 쓰면 인식하지 못해 블록 컴파일이 실패한다. 위치 번호(`ORDER BY 1`)로 바꿔 해결한다.
- 실행 순서(FACT 3개 → DIM 2개)는 같다. 다른 줄과 주석은 바꾸지 않았다.
