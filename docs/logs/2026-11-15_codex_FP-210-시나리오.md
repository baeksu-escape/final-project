## 무엇을, 왜 바꿨나

- 광희 님 FP-167(PR #118)의 기준값 `GET /api/members/me/scenario-base`와 결과 `POST /api/members/me/scenario-recalculate`를 사용한다. 계산은 서버에서 하고 결과 응답을 그대로 쓴다.
- 첫 화면은 변화 조건 0으로 즉시 한 번 요청한다. 이후 입력은 300ms 동안 모아 요청하고, 응답 전에는 직전 결과를 유지하며 늦은 응답은 무시한다. 미리 정한 조건 버튼도 제공한다.
- 입력 오류는 `fieldErrors` 메시지를 우선 표시하고, 404 등 요청 오류는 서버 메시지를 표시한다. 401은 공통 API 처리로 로그아웃한다. `policyRate`의 null을 보존한다.
- 광희 님 요청으로 브라우저 계산 `calculateScenario.js`와 화면 전용 mock을 삭제했다. 금리 하락 시 변동금리 상환액 반영, 대출별 금리 하한 0%, HALF_UP 규칙을 화면에서 따라 계산하지 않는다.
