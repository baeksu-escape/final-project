# 서비스 등급 표기를 Poor에서 Caution으로 통일

- **날짜:** 2026-11-04
- **작성자:** kgh / Claude Code
- **브랜치:** `KGH_Work`
- **관련 N-ID:** N-04, N-12, N-18, N-25 (등급을 보여 주는 기능)
- **관련 결정:** D-01 (등급 경계 점수는 계속 미정)

## 무엇을, 왜 바꿨나
- 서비스 3단계 등급의 세 번째 이름이 문서마다 달랐다. 팀 문서(`docs/ai/`)는 `Poor`, 더미 DB·데이터 패키지는 `CAUTION`이었다.
- 더미 DB(`MEMBER_CREDIT_GRADE.GRADE_BAND_CODE`)와 데이터 패키지가 이미 `CAUTION`을 쓰고 있어, **`CAUTION`으로 통일**하기로 했다 (결정: kgh).
- 이름만 바뀐다. 등급 경계 점수(D-01)는 그대로 미정이다.

- DB: 없음 (`GRADE_BAND_CODE` 허용값 `GOOD`/`STANDARD`/`CAUTION`은 원래 이 값이다)
- API: 없음
- 영향을 받는 기능·팀원: 등급을 화면·코드에 쓰는 팀원. 아직 `Poor`로 만들었다면 `CAUTION`(코드 값) / `Caution`(문서·표시 영어 표기)으로 바꿔야 한다. 화면에 보이는 한글 이름은 이 변경으로 정해지지 않았다.
