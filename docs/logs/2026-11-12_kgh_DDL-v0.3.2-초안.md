## DB·API 변경
- DB: `FACT_DONG_LIVING_POP`·`FACT_HFS_WORKER_STAT`·`BOARD_POST_LOG` 신설. `DIM_SERVICE_CATEGORY` 매핑, `CONTENT_REPORT` 상태 CHECK, `APP_USER` 탈퇴 처리와 `USER_LOAN` 동의 연결, 대안 데이터 6개 표 동의 CHECK·FK 등을 변경했다.
- DB: W5로 `APP_USER`의 사업장 동·업종 열과 FK 2개를 삭제했다.
- DB: W6로 `SYSTEM_LOG`와 시간순·구분별 인덱스 2개를 추가했다.
- API: 없음.
- 영향을 받는 기능·팀원: 범영(Oracle 적재 확인 후 PR), A팀 Spring(탈퇴·인증 기록·동의 종료 삭제, 접두어 예약, 게시글 조건부 UPDATE와 로그), C조(통계 적재·매핑), 경환(생성기 DDL 해석기에 `||`·`TO_CHAR`·`LIKE … ESCAPE`·`NOT LIKE` 지원, `01_create_tables.sql` 교체·시드 재생성).

## 확인
- 확인함: w8 검수에서 해당 CHECK를 뺀 사본의 생성기 파싱·400명 시드는 W6 이전 50표 기준으로 확인했다. 51표는 정적 집계만 했고 제약 276·인덱스 28·컬럼 주석 165이다. w8·Codex 정적 검수를 했다.
- 확인 못 함: Oracle 21c 실행, 생성기의 v0.3.2 정식 대응, 법령 원문 일부.
