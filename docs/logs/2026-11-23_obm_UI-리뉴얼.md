## 무엇을, 왜 바꿨나
- 예전 UI(데모 v2)는 색이 여러 개 섞이고, 가로 탭 9개가 한 줄에 몰리고, 화면마다 모양이 달라 "AI가 만든 티"가 났다.
- 토스·카카오뱅크 웹사이트 구성을 참고해(직접 접속·캡처로 확인) 흰 바탕·파랑 강조 하나·큰 숫자의 금융 서비스형으로 바꿨다. 사진·로고·문구는 가져오지 않았다.
- **API 호출·상태·검증 로직은 바꾸지 않았다.** 라우트 경로·클래스 이름도 유지해, 공통 클래스를 쓰는 다른 팀 화면은 자동으로 새 디자인이 된다(합친 뒤 들어온 관리자 통계 FP-162도 그대로 적용됨).
