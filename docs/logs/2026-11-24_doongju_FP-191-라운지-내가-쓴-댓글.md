# 신용 라운지 '내가 쓴 댓글' 탭 추가(COMM-09), '이야기 중' 카드 삭제

- **날짜:** 2026-11-24
- **작성자:** 동주(C팀) / Claude Code
- **브랜치:** `feature-C/FP-191-loungeMyComments` (Jira FP-191)
- **관련 N-ID:** N-06 (신용 라운지, 세부 N-ID 미정)
- **관련 결정:** 11/24 동주: 라운지 목록 위 '이야기 중' 카드를 없애고 탭 '내가 쓴 댓글'을 둔다. 이 탭에서는 글 검색창을 숨긴다. 마이페이지 [게시판관리]는 빼기로 해서(우찬) COMM-09는 라운지에서만 쓴다

## 무엇을, 왜 바꿨나
- 라운지에서 내 댓글을 모아 볼 수 없었다. 탭 줄(전체보기·댓글 많은 글·내 글) 끝에 '내가 쓴 댓글'을 추가했다. 글 목록과 같은 줄 모양으로 제목 자리에 댓글 내용, 오른쪽에 닉네임·등록일을 보여 주고, 누르면 그 글을 연다.
- 글 목록 응답에는 내 댓글 정보가 없어 정의서에 제안(🟡)으로 있던 COMM-09를 구현했다.
- 목록 위 '이야기 중' 카드 3개와 그 CSS(`.lounge-hot*`)를 지웠다.
