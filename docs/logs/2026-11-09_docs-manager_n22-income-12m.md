# 월 소득 12개월 입력 확정에 맞춰 N-05·N-22 문서 수정

- **날짜:** 2026-11-09
- **작성자:** 문서 담당자 / Claude
- **브랜치:** (문서 작업, PR로 올릴 예정)
- **관련 N-ID:** N-05-2, N-05-8, N-22-2, N-22-3, N-22-5, N-22-6
- **관련 결정:** 투표 D1(최소 기록 기간)

## 무엇을, 왜 바꿨나
- 팀이 월 소득을 12개월 입력받기로 확정해, 기능 명세서 시트(v3 탭)의 해당 행이 바뀌었다. AI 문서를 시트에 맞췄다.
- N-22-2 정보 부족 처리는 삭제됐다(12개월을 모두 받으므로 정보 부족 상태가 없다).
- N-22-5 "비수기 경고 판정"은 표현이 애매해 "소득 부족 달 확인"으로 구체화됐다: 최근 12개월 중 소득이 월 고정지출보다 적은 달을 찾아, 다시 오기까지 남은 개월 수와 모자란 금액을 알린다.
- N-22-6은 "월별 소득 차트·소득 부족 달 미리 알림"으로 바뀌었고, 정보 부족 안내 문구가 빠졌다.
