- 광희 요청: 상담 채팅 위젯 캡처처럼 만든다. 다른 서비스의 로고·색·문구는 가져오지 않고 배치만 공통 재료(파랑 강조·흰 카드·토큰)로 만들었다.
- 결정(광희)
  - 닫힌 상태에서 버튼 위에 안내 카드 + 질문 말풍선 2개를 띄운다.
  - ×로 닫으면 다시 로그인할 때까지 숨긴다.
  - 버튼은 **브라우저 창 오른쪽 아래 구석**에 둔다. 바로 위 두 절의 "카드 옆 위치·넓은 화면 빈칸" 계산은 지웠다.
- 동작
  - 말풍선에는 질문 버튼 중 글자가 짧은 2개가 나온다(표시 순서 유지). 누르면 패널이 열리고 그 답이 바로 보인다(횟수 안 줄어듦).
  - 카드를 누르면 패널이 열린다.
  - ×를 누르거나 패널을 한 번 열면 안내를 그만 띄운다. `sessionStorage`의 `avenue.glossaryTeaserHidden.<회원 번호>`에 기억해, 같은 탭에서는 화면을 옮기거나 새로고침해도 안 뜨고, 다른 회원이나 새 탭(다시 로그인)에서는 다시 뜬다. 저장소를 못 쓰면 try/catch로 넘긴다.
  - 말풍선에 질문이 필요해서, 안내가 보이는 동안에는 화면이 처음 뜰 때 HELP-02를 한 번 부른다(이전에는 패널을 처음 열 때).
- 바뀐 파일
  - `GlossaryHelperDialog.jsx`: 안내 `aside`, 카드·말풍선·×, `useAuth`로 회원 번호
  - `glossaryHelper.css`: 위치 계산 삭제 → 구석 고정, `.gh-teaser`·`.gh-chip`·`.gh-teaser__*` 추가
  - `features.md`
- 확인(mock, 화면 없는 Edge, 실제 마우스)
  - 처음 카드 + 말풍선 2개("점수 영향도(SHAP)는 어떻게 읽나요?", "DSR(상환 부담률)이 높으면 어떤 뜻인가요?")
  - 말풍선 → 패널이 열리며 그 답, 닫아도 안내 안 뜸, 다른 화면에서도 안 뜸
  - 저장소를 지우면 다시 뜸 → × → 새로고침해도 안 뜸
  - 다른 회원(self)에게는 뜸 → 카드 → 패널 열림
  - 390px 화면 안·가로 넘침 없음, 2560px 버튼이 구석(아래 24px), 관리자 화면에는 없음
  - 캡처: 같은 폴더 7·8번
- 🆕 11/27 광희: 서비스는 PC 브라우저에서만 쓴다 → `glossaryHelper.css`의 휴대폰 전용 규칙(`@media (max-width: 480px)`)을 지웠다. 창을 좁혀도 패널·안내 너비는 `min(…, 100vw - 32px)`로 화면 안에 들어온다. 위 확인 중 390px 항목은 이제 대상이 아니다.
