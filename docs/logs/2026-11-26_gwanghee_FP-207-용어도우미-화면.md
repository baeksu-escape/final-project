- **작성자:** 광희 (C조) / Claude Code

- **관련 N-ID:** N-32, N-32-1
- **관련 결정:** AGENTS 3-2(새 CSS는 프론트 담당 영역), D-21(자유 질문에 넘길 정보, 이번 범위 밖)

## 무엇을, 왜 바꿨나
- 위쪽 바 [알림] 옆에 [용어 도우미] 버튼을 두고, 누르면 공통 `Modal`로 질문 버튼 4개와 답을 보여 준다(HELP-02, FP-181).
- 명세는 "오른쪽 아래 떠 있는 창"이지만, 그 모양은 새 CSS가 있어야 한다. 광희 결정(11/26)으로 기존 클래스와 공통 컴포넌트만 쓰는 위쪽 바 버튼과 가운데 창으로 만들었다. features.md N-32에 ⚠️ UI 줄을 남겼다.
- 질문 목록은 처음 열 때 한 번만 불러온다. 위쪽 바는 화면을 옮겨도 그대로라, 다시 열어도 다시 부르지 않고 고른 질문도 남는다.
- 질문 버튼은 질문 횟수를 줄이지 않는다(N-32-1). 자유 질문(N-32-2, HELP-03)은 AI 제공사를 정한 뒤 만든다. 창 아래에 "직접 질문하기는 준비 중이에요." 안내만 둔다.
- 관리자 화면에는 버튼이 없다(위쪽 바의 사용자 전용 블록 안에 넣음).

## 확인
- 확인함
  - `npm run lint`(`features/ai`, `AppHeader.jsx`) 오류 0, `npm run build` 성공
  - mock 모드 화면 확인(화면 없는 Edge)
    - 사용자 `employee`: 위쪽 바가 `알림 | 용어 도우미 | 마이페이지 | …` 순서로 나온다. 누르면 질문 4개와 "위 질문을 눌러 보세요."가 보이고, 창 안에 포커스가 간다.
    - 2번 질문을 누르면 그 버튼만 `aria-pressed=true`가 되고 답이 바뀐다. Esc로 닫힌다.
    - 다른 화면(`/my-credit`)으로 옮긴 뒤 다시 열면 '불러오는 중' 없이 바로 4개가 보이고, 고른 질문이 남아 있다.
    - 관리자 `admin`: 위쪽 바에 버튼이 없다(`비밀번호 변경 | 라이트 | 로그아웃`).
    - 390px 너비에서 페이지 가로 넘침은 없다.
- 확인 못 함·남은 문제
  - **좁은 화면에서 가장 긴 4번 질문의 글자가 버튼 밖으로 넘친다.** 공통 `.button`이 `white-space: nowrap`이라 새 CSS 없이는 고칠 수 없다. 프론트 담당에게 "용어 도우미 질문 버튼은 줄바꿈 허용" 스타일을 요청할 예정이다.
  - 오류 상태는 화면에서 따로 만들어 보지 않았다(mock은 로그인하지 않으면 401이고, 401은 로그아웃 흐름으로 간다). 코드상 `Notice`와 [다시 시도]로 다시 부른다.
  - 실제 서버 호출은 FP-181 테스트(`ChatbotControllerTest`·`ChatbotMapperIT`)로 갈음한다.
