# FP-88·89 저장 리포트 조회와 회원 범위·버전별 조인 검사

- **날짜:** 2026-11-14
- **작성자:** 경환 / Codex1·Codex2 (root 계획·통합 검토)
- **브랜치:** `KGH_Work`
- **관련 N-ID:** N-12-1·3·6, N-14-1·2·3·4
- **관련 작업:** FP-88, FP-89
- **관련 결정:** D-01(등급 경계), D-27(미정 화면 항목)

## 무엇을, 왜 바꿨나
- 저장된 SERVICE 평가를 회원 번호로 제한해 최신 1건 또는 요청 번호별로 조회하는 DTO·서비스·MyBatis 매퍼를 추가했다. 같은 평가 시각이면 평가 번호 내림차순으로 최신을 정한다.
- 등급 경계는 평가 당시 cutoffVersion으로, SHAP와 피처 사전은 평가·피처 코드·featureSetVersion으로 연결한다. SHAP는 저장된 전체 순위를 반환하며 개수 제한이나 재정렬을 하지 않는다.
- 대안 점수가 낮거나 같은 결과와 미산출·NULL을 보존한다. 두 모델을 비교할 수 없으면 점수 차이·등급 변화는 NULL이다.
- Codex2는 root의 테스트 초안을 보완해 DB 없는 서비스 mock 검사와 실제 XML 파싱·JDBC 바인딩 검사를 수행했다. 이번 작업에 컨트롤러·인증·공통 설정 연결은 포함하지 않는다.

## DB·API 변경
- DB: DDL·테이블·컬럼 변경 없음. 기존 ASSESSMENT·SCORE_GRADE_BAND·ASSESSMENT_FACTOR·DIM_FEATURE 조회 SQL 추가.
- API: HTTP 경로·컨트롤러 추가 없음. 내부 조회 응답 DTO에 요청 번호·평가 시각·기준월·직군·산출 상태/이유·모델 버전·두 모델 결과·비교 값·등급 경계·SHAP·저장 요약을 정의했다. 아직 HTTP 계약 확정·연결을 뜻하지 않는다.
- 영향을 받는 기능·팀원: FP-88·89, 리포트 프론트 담당, 인증 담당, 평가 결과 저장 담당.

## 확인
- 확인함: Java 17.0.19, Maven wrapper distribution 3.10.0에서 최종 지정 테스트 **13개 성공 / 실패 0 / 오류 0 / 건너뜀 0** (서비스 9개, 매퍼 4개), BUILD SUCCESS.

  ```powershell
  $env:JAVA_HOME='C:/Program Files/Java/jdk-17.0.19'
  ./mvnw.cmd '-Dtest=ReportServiceTest,ReportMapperTest' test
  ```

- 확인함: 서비스의 소유 회원 전달, 미존재 Optional.empty와 하위 조회 생략, 요청 조회 성공, 잘못된 내부 입력 차단, 대안 점수 하락·동일 점수·미산출·NULL 보존, 8개 SHAP 항목의 저장 순위 유지, 저장 메타데이터·경계 전달.
- 확인함: 실제 XMLMapperBuilder 파싱, 최신 SERVICE 평가 SQL의 회원 제한·최신 정렬, requestId+USER_ID 조건, 두 하위 조회의 회원+평가 번호 조건, 버전별 조인과 SHAP 개수 제한 없음. ParamNameResolver와 DefaultParameterHandler를 사용해 실제 인터페이스의 @Param에서 mock PreparedStatement까지 값이 바인딩됨을 검사했다.
- 실행 중 문제: 첫 명령은 PowerShell의 쉼표 인수 파싱 오류로 실행되지 않았다. `-Dtest=...`를 따옴표로 감싸 수정했다. 샌드박스 실행은 wrapper 시작 시 `Cannot index into a null array / Cannot start maven from wrapper`로 중단됐고, 동일 명령의 승인된 실행에서 성공했다. wrapper·pom·의존성은 수정하지 않았다.
- 확인 못 함: Oracle 실제 SQL 실행·조회 결과 매핑·회원 격리 통합 검증. 데이터소스 없이 mock 및 XML·바인딩만 검사했다.
- 확인 못 함: 실제 평가 결과 저장에서 조회 응답까지 이어지는 연동. 고정 합성 예제를 사용했으며 실제 데이터·비밀값은 읽거나 출력하지 않았다.

## 다음 사람이 알아야 할 것
- **인증 PR 대기:** 인증 회원 번호 전달과 컨트롤러 연결은 후속 작업이다. 서비스의 Optional.empty는 아직 HTTP 상태나 공통 오류로 변환되지 않는다. 타인 요청과 미존재 요청은 서비스에서 모두 빈 결과다.
- **Oracle 미검증:** XML 파싱·바인딩 성공은 Oracle 실행이나 실제 ResultSet 매핑 성공을 보장하지 않는다.
- **실제 저장 연동 미검증:** 평가 저장 담당과 동일 버전·요청 번호 계약 및 저장 후 조회를 별도로 확인해야 한다.
- **타임존 계약 미정:** Oracle TIMESTAMP를 LocalDateTime으로 전달한다. UTC·한국 시간 등 변환 규칙은 확정하지 않았고 시간대 변환도 하지 않는다.
- **mapper 경로 설정 미연결:** 테스트는 `mapper/credit/ReportMapper.xml`을 직접 읽는다. 애플리케이션의 mapper-locations·부팅 시 자동 등록은 연결·검증하지 않았다. 공통 설정은 담당자 작업이 필요하다.
- **Claude 검수:** 구현·테스트·로그 완료 보고 후 root가 기존 api-reader에 검수를 요청한다. 이 로그의 사람 검수란은 비워 둔다.
- **Claude 로직 검수:** 완료, 로직 결함 없음. 이는 최종 검수가 아니며 사람 검수란은 비워 둔다.
