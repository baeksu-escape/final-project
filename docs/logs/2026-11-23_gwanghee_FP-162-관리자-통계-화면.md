## 무엇을, 왜 바꿨나
- 관리자 메뉴 "직군·연령별 통계"(`/admin/stats`)가 빈 화면(`PlaceholderPage`)이었다. FP-161 API로 실제 화면을 만들었다.
- 화면 구성
  - 머리: 직군별·연령대별 전환(`SegmentedControl`), 기준 모델 표시("모델 LGBM-BASE-0.2 기준")
  - 안내: ACTIVE 모델 평가만 세고, 계산 인원 5명 미만인 값은 숨긴다(—)
  - 요약 4칸(N-26-2): 평가 고객 수·가입 회원 수, 평균 점수 기존 → 대안·상승폭, Standard 이상 비율 기존 → 대안, 오늘 산출
  - 전체 등급 분포(N-26-3): 등급마다 기존·대안 비율 막대(공통 `CompareBar`, 동주 님 `JobRejectBars`와 같은 방식)
  - 그룹별 표(N-26-4): 인원(기존 산출), 평균 점수·Standard 이상(기존 → 대안), 상승폭, 대안 등급 분포
- 숨김 처리
  - 서버가 `null`로 보낸 값은 '—'로 보인다.
  - 기존 분포만 숨겨지면 0% 막대로 오해하지 않게, 대안 분포만 글자로 보여 주고 "기존 모델 산출 n명이라 숨김"을 적는다.
- 등급 기준 안내(PR 리뷰 반영, 11/23): 등급은 평가 당시 등급 구간으로 저장되고 ADM-03은 등급 구간 버전을 거르지 않는다. CUT-0.3 전환(#137) 전 평가가 남아 있으면 등급 분포·Standard 이상 비율에 이전 기준이 섞일 수 있어, 맨 위 안내 아래에 한 줄(`hint`)로 알린다.
- 구분을 바꾸면 다시 읽는다. 받은 결과에 구분을 함께 저장해, 바꾼 직후 이전 구분의 숫자가 새 제목 아래 보이지 않게 했다.
- 오류 처리: 비밀번호 변경이 필요한 관리자는 공통 `useAdminErrorHandler`로 로그인 화면에 보내고, 그 밖의 오류는 `adminErrorMessage` 문구로 보여 준다.
- CSS·className은 새로 만들지 않았다. 공통 컴포넌트(`Card`·`Chip`·`Notice`·`SegmentedControl`·`CompareBar`)와 기존 클래스(`page-head`·`l-kpis`·`l-stack`·`data-table`·`hint`·`num`)만 썼다.
