# 모델 0.3 학습 옵션, VALID 사전 기준 점검, TEST 평가 코드 확장

- **날짜:** 2026-11-26
- **작성자:** 최재욱(B팀 모델·정의서 담당) / Claude Code
- **브랜치:** `feature-B/label-v37-model` (`feature-B/label-v37` 위에 쌓은 브랜치, Jira 키 확정 전 임시 이름)
- **관련 N-ID:** N-12-2(점수 모델 학습), N-25(모형 성능 비교)
- **관련 결정:** 정의서 10장 C33(모델 기준), C34(VALID 결과), C35(TEST 사전 기준, 11/26 재욱 결정 VALID ±0.02)

## 무엇을, 왜 바꿨나
- 데이터 v3.7.0으로 모델 0.3을 학습하기 위해 단조 제약 목록 v03과 선택 옵션을 추가했다. 0.2의 목록과 `--monotone` 동작은 그대로다.
- C33 기준 (a)~(f)를 판정하는 `check_v03.py`를 결과를 보기 전에 만들었고, VALID에서 11개 항목이 모두 통과했다.
- `final_test_eval.py`에 `--version`을 넣어 0.3 설정(C35 범위, 후보 등급 경계, C34 해시 대조, 별도 기록·결과 파일)을 추가했다. 기본값은 0.2다.

## DB·API 변경
- 없음. 서버 모델 파일(`artifacts/`, 0.2)도 바꾸지 않았다.
- 영향을 받는 기능·팀원: 없음(서비스 반영 전).

## 확인
- 확인함: FastAPI 테스트 250개 통과. 0.3 VALID 리허설에서 모델 파일 재현 "같음", C35 기준값 4개 "같음", 모든 AUC 범위 안. 0.2 VALID 리허설도 C26 기준값 4개 "같음".
- 확인 못 함: TEST(실행하지 않음), DB 등록·등급 구간 전환·시드 평가, 서비스 연동, 0.3 모델 파일의 서비스 로더 확인.

## 다음 사람이 알아야 할 것
- TEST는 추적 파일을 커밋한 뒤 `python -m training.final_test_eval --version 0.3 --split TEST --confirm-test-once`로 **한 번만** 실행한다.
- 모델 파일은 로컬 `fastapi_server/data/model_v03/`(Git 제외)에 있고 해시는 C34에 있다. 다시 학습해 덮어쓰면 설명 파일의 시각이 달라져 해시 대조에서 멈춘다.
- 비금융 효과 라벨에서 대안의 우위는 +0.0193이다(0.2의 VALID는 +0.0511, 데이터·라벨이 달라 직접 비교하지 않는다).
