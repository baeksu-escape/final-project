- **작성자:** 경환 / Codex1(loans·통합), Claude(simulation 실제 구현 인수), Codex2(초안·교차 검수), root(계획·설계·통합 검토)

## 무엇을, 왜 바꿨나

- UI 원본을 참고해 임시 상품 9종의 목록·4필터·상세·회원별 즐겨찾기·신청 안내를 추가했다.
- 추가 승인: 모든 필터 결과를 즐겨찾기 우선·같은 그룹 내 점수 조건 충족 우선으로 정렬한다. 동률은 원 카탈로그 순서, NULL 점수 확인 불가와 직군 필터 분리는 유지하며 배열 원본은 바꾸지 않는다.
- 목록·상세·시뮬레이터 추천에서 공용 상품 카드와 즐겨찾기를 사용한다.
- 목록·상세의 상품·점수 조회 오류에 재시도를 제공하고 정상 미산출은 별도 안내한다. 이전 요청·회원의 늦은 응답은 표시하지 않는다.
- `404 + ASSESSMENT_NOT_FOUND`는 정상 평가 없음으로 처리한다. 배너는 adapter의 providerTheme를 사용하고 상세 등급은 저장 경계와 일치할 때만 표시한다.
- 시뮬레이터는 10개 입력·500ms 자동 계산·기준값 되돌리기·예시값 채우기·결과 비교·공용 상품 추천을 제공한다. 추가 승인으로 기존 계산 버튼을 제거했으며 실패 시 재계산만 남긴다. 실제 모델·금리/한도 조회가 아닌 UI mock 시연이며 서버 계약과 분리한다.
- `/loans`, `/loans/:productId`를 추가하고 기존 `/simulator`에 담당 페이지를 연결한다. 기존 메뉴·경로 이름은 유지한다.

## DB·API 변경

- DB 변경 없음. 상품·즐겨찾기 서버 API 경로를 확정하지 않았다.
- 서비스 시드는 현재 17종, UI는 9종으로 서로 다르다. root에 보고하고 UI mock만 사용했다.
- UI 상품 식별자는 DB productId가 아니다. `dbProductId=null`이며 자동 매핑하지 않는다.
- mock 즐겨찾기는 회원·카탈로그 버전별 sessionStorage로 격리한다. 실제 모드에서 상품 API 미연결을 오류로 표시하고 mock 자동 대체는 하지 않는다.
- mock 통합 계약·필드 대조·제약: `frontend/src/features/loans/README.md`.
- 실제 서버·Oracle 연결은 미검증이다. 이번 작업은 mock 화면 범위이며 서버 코드를 추가하지 않았고 비밀 설정을 열지 않았다.
