## 무엇을, 왜 바꿨나
- 리포트 백엔드 담당이 범영으로 정리되어 중복 구현 및 `reportService` 빈 이름 충돌을 막기 위해 기존 credit 리포트 백엔드와 테스트를 제거했다.
- 신용 리포트 mock을 assessment 응답 필드에 맞췄다. 모델별 피처 칩은 응답에 없어 표시되지 않으며, 지난 평가 대비 값은 MEM-06 진단 내역에서 조회한다.

## 확인
- 확인함: 기존 삭제 대상 7개 파일의 외부 참조를 검색했다. `npm.cmd run lint` 통과. mock에서 제거한 피처 칩은 해당 응답 필드가 없어 화면에 나오지 않고, 지난 평가 변화는 MEM-06 조회를 유지한다.
- 확인 못 함: 백엔드 테스트는 Maven wrapper 오류 후 설치된 Maven으로 재시도했으나, Maven Central 연결이 권한 거부되어 의존성 확인 단계에서 중단됐다.
