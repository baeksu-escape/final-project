# FP-203 후속: 현금흐름 과거 월 실적 months(N-21-9)·화면 전망 조건(N-21-2)·소득 표준편차 추가

- **날짜:** 2026-11-17
- **작성자:** 광희 (C조) / Claude Code
- **브랜치:** `feature-C/FP-203-cashflow-past-months` (최신 develop에서 새로 만듦)
- **관련 N-ID:** N-21-9, N-21-2, N-21-1, N-21-5, N-22-3
- **관련 결정:** DDL 11/10 기준월 = `USER_INCOME_MONTH`의 가장 늦은 달

## 무엇을, 왜 바꿨나
- 현금흐름 화면(경환 님 FP-94·96)은 과거 실적 뒤에 전망을 이어 그린다(N-21-9). 그런데 현금흐름 API는 앞으로의 전망(`monthlyForecasts`)만 주고 과거 달 목록을 주지 않았다.
- 경환 님 요청대로 화면 adapter와 같은 이름으로 `months: [{ baseMonth, incomeAmount, expenseAmount }]`를 응답에 **추가**했다. 기존 필드는 바꾸지 않았다.
- 급여소득자 월급 펼치기와 소득 기준월 처리는 서버가 이미 계산에 쓰는 이력을 그대로 내보내서 맞췄다. 화면에서 다시 할 필요가 없다.
- 예상 점수(N-21-8, DIAG-09)는 이번 범위가 아니다(FP-170). 그때까지 화면은 "변경 없음/준비 중"으로 둔다.
- (두 번째 커밋) 경환 님 확정에 따라 현금흐름 GET에 명세 N-21-2·화면과 같은 조건 3개를 **추가**했다.
  - `incomeVariationPct`(0~200): 전망 소득 = 평균 + (과거 같은 달 − 평균) × %. 0%면 매달 평균, 100%면 과거 패턴 그대로. 같은 달이 없으면 평균, 0원 아래로는 안 내려감.
  - `fixedExpenseAmount`(0 이상): 보내면 저장된 고정지출(FIXED) 자리만 그 값으로 바꾼다. 생략하면 저장값.
  - `paymentStatus`(ON_TIME·DELAYED): 값만 검사한다. 예상 점수(DIAG-09)에서 쓴다.
  - 모두 생략하면 결과는 이전과 같다. 기존 % 조건은 그대로 두었다.
- 소득 변동성 응답에 `standardDeviation`(모표준편차, 소수 2자리)을 추가했다. `unavailableReason`·`source`는 경환 님과 합의해 넣지 않았다(소득 없으면 지금처럼 404).
- 응답 필드 이름은 서버 이름을 유지하고, 경환 님이 화면 adapter에서 바꾼다.

## DB·API 변경
- DB: 없음
- API: `GET`·`POST /api/diagnosis/cash-flow/forecast`(B팀 정의서 DIAG-08-1·DIAG-08) 응답에 `months[]` **추가**. 경로·기존 필드 변경 없음.
  - GET: 소득 기준월까지 최대 12개월(자영업자·프리랜서는 저장된 달만, 급여소득자는 월급을 12개월로 펼침). `expenseAmount`는 기준월의 월 지출 합계(모든 그룹)라 매달 같은 값이다.
  - POST: 요청의 `past12MonthsHistory`를 같은 모양으로 돌려준다.
- API (2): GET 현금흐름 쿼리에 `incomeVariationPct`·`fixedExpenseAmount`·`paymentStatus` 추가(범위 밖 400 `INVALID_INPUT`, field = 쿼리 이름). `GET`·`POST /api/diagnosis/income-volatility` 응답에 `standardDeviation` 추가. 계산기 `forecastCashFlow`는 기존 시그니처를 남기고 변동 폭을 받는 오버로드를 추가했다.
- 영향을 받는 기능·팀원: 경환 님 현금흐름 화면(이 필드로 연결). B팀 API 정의서(목록) 반영 요청 필요.
- (3, 11/18) `docs/spec/api_spec.md`의 기존 FP-203 절에 위 추가분을 **추가만** 했다(기존 문장 삭제 없음). 요청·응답 상세를 어디에 둘지는 범영 님 결정 전이라, 정해지면 그에 맞춘다. 예시 값은 진단 mock을 직접 호출해 맞췄다.

## 다음 사람이 알아야 할 것
- 저장된 소득이 12개월보다 적은 자영업자·프리랜서는 `months`가 12개보다 짧다. 화면 adapter는 12개를 요구하므로, 점수 산출 조건(12개월 필수)을 채운 회원이 아니면 화면에서 안내가 필요하다.
