- **날짜:** 2026-11-16
- **작성자:** KGH / Codex

- **관련 N-ID:** N-12-2, N-14
- **관련 결정:** O-17

## 무엇을, 왜 바꿨나
- DDL 지문은 CRLF/LF와 무관하게 DDL 바이트를 LF로 정규화한 뒤 SHA-256을 계산하도록 생성기와 테스트를 맞췄다.
- FS-DRAFT 39개 시드를 실행 묶음에 추가하고, 재실행 전에 `DIM_FEATURE`가 비어 있는지 확인하도록 했다. `99_check.sql`과 `seed_report.json` 기대 행 수도 39로 반영했다.
- 이 브랜치에는 FP-209 정렬 수정(`cbd8774`)과 대출 시드 문구 보강(`b5d2024`)이 포함되어 있다.

## DB·API 변경
- DB: DDL 변경 없음. 초기화·최초 시드 묶음에 DIM_FEATURE FS-DRAFT 39개 적용
- API: 없음
- 영향을 받는 기능·팀원: 평가 저장 전 피처 사전 준비

## 확인
- 확인함: 임시 출력 묶음에서 `01_create_tables.sql`과 기존 10~24번 회원·상품 시드 파일은 작업 트리와 바이트 동일하고, 25번 피처 시드는 지정 원본과 바이트 동일함을 확인했다. 정규화 지문은 Git blob 기준과 일치한다. 정적 스키마 테스트 5건 및 RunAll 규칙 테스트 2건 통과.
- 확인 못 함: 전체 unittest 51건 중 자산 보조 테스트에서 실행 환경의 `dateutil` 모듈 누락으로 1건 오류(3건 건너뜀). 전체 더미 원천 재생성은 `build_members` 단계의 `PyYAML` 누락으로 중단되어, 기존 시드·보고 행 수를 사용해 실행 묶음만 임시 재생성했다. env 값은 출력하지 않았다.

## 다음 사람이 알아야 할 것
- FS-DRAFT 시드는 10~24번 시드 뒤, `99_check.sql` 앞에서 실행한다. `run_seed_only.sql` 사전 검사는 DIM_FEATURE가 비어 있지 않으면 중단한다. FS-DRAFT를 참조하는 평가 요인이 생긴 뒤에는 피처 시드 SQL을 재실행하지 않는다.
- `avenue_ddl.sql`, `01_create_tables.sql`, 회원·상품 시드 10~24번과 원본 `docs/spec/sql/seed/avenue_seed_dim_feature_fs_draft.sql`은 수정하지 않았다.
